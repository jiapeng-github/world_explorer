# 世界大百科 · 全新产品功能清单

日期：2026-11-01  
状态：功能设计讨论稿。本文件是新方案，不代表现有 App 已实现。  
面向用户：以 8 岁孩子独立使用为主，也支持亲子共读。  
本阶段交付：产品结构、功能清单、内容标准与实施顺序。页面布局和视觉风格在下一阶段重新设计。

## 1. 产品定位

一本可以探索、阅读、聆听和比较的世界百科。孩子可以从一个国家、一张地图、一幅风景或一个问题出发，理解不同地方的自然环境与人们的生活。

三条核心路径：

1. 地图探索：找到一个地方 → 看国家概览 → 了解地形、城市与地标 → 深入阅读。
2. 问题探索：对一个问题感兴趣 → 阅读专题 → 对照不同国家 → 保存自己的发现。
3. 自由阅读：搜索或浏览国家 → 选择主题 → 看图、读文、听讲解 → 跳转相关知识。

内容阅读始终开放。阅读进度用于续读，互动题用于理解；不以答题、签到或收集奖励作为解锁知识的条件。

## 2. 一级导航

| 入口 | 解决的问题 | 包含内容 |
| --- | --- | --- |
| 发现 | 今天可以了解什么？ | 精选国家、世界问题、主题路线、继续探索 |
| 地图 | 它在哪里？周围有什么？ | 世界图集、国家与地标定位、地形和主题图层 |
| 百科 | 我想系统了解一个国家或主题 | 国家目录、主题目录、搜索、国家比较入口 |
| 我的 | 我看过什么、还想知道什么？ | 收藏、阅读足迹、探索笔记、阅读设置、家长入口 |

国家详情、文章、地标详情、专题和互动题是这些入口下的内容页面。手机和平板使用同一套信息结构，布局分别设计。

## 3. 优先级说明

- **P0：新版首发必需。** 首发验收以这些功能和相应内容都可用为准。
- **P1：首发后的增强。** 基础体验稳定后逐项加入。
- **P2：后续评估。** 需要额外内容、服务或验证，不列入首发承诺。

### C. 国家百科

每个完整国家包包含以下十个栏目。栏目独立进入，也可以连续阅读；专题文章可以同时关联多个栏目。

| 编号 | 栏目 | 内容与功能 | 优先级 |
| --- | --- | --- | --- |
| C01 | 国家名片 | 名称、国旗、首都、位置、常用语言、货币、面积，以及三个最值得先了解的特点 | P0 |
| C02 | 地理与气候 | 所在区域、周边海陆、主要地形、河流、季节差异；正文可联动地图 | P0 |
| C03 | 人们与语言 | 日常问候、不同地区和群体的语言与生活差异，避免把全国居民写成同一种生活方式 | P0 |
| C04 | 日常生活 | 学校、居住、交通、市场、运动等具体生活场景，并标明案例所处地区 | P0 |
| C05 | 饮食与物产 | 代表食物、主要食材、地方差异，以及它们与地理环境的关系 | P0 |
| C06 | 艺术与节日 | 音乐、服饰、手工艺、建筑风格与节庆；解释背景和适用地区 | P0 |
| C07 | 城市与地标 | 代表城市和自然、人文地点；每个地点都有图片、位置与一段可理解的介绍 | P0 |
| C08 | 动物与生态 | 代表动物、植物、生境及人与自然的关系；物种分布不简单等同于国界 | P0 |
| C09 | 历史故事 | 简短时间线连接具体人物、地点或生活变化，提供适龄扩展阅读 | P0 |
| C10 | 有趣问题 | 解释“为什么”和“怎么形成”，链接相关主题文章与其他国家 | P0 |
| C11 | 国家间比较 | 并排比较两个国家的地理、气候、语言、饮食与生活，呈现共同点和差异 | P1 |

国家概览先呈现位置、实景和三个特点，再提供栏目入口。人口等会变化的数据必须附年份；历史事件和文化习俗提供语境，不使用未经解释的排名或绝对化概括。

## 5. 内容深度与首发范围

以下是规划目标，需要在内容制作阶段逐项落实。

### 一个完整国家包的最低标准

- 十个核心栏目都有实际内容。
- 至少八篇主题文章；每篇围绕一个具体问题，含二至四个小节、图注、难词解释与来源。
- 至少五处可定位的地标或自然景观，各自有独立介绍。
- 至少八张有授权、与内容对应的实景照片；另可配专门制作的示意图。
- 四至六个经过筛选的历史节点，关联适龄历史故事。
- 至少五个有解释、有依据的常见问题；互动题与正文直接对应。
- 资料足以支持基本国家比较，并关联至少一个跨国专题。

照片和插画各有明确用途：实景承担辨认地方和观察环境的任务；示意图解释过程、尺度与关系；创作插画服务叙事，并标明性质。

### 完整新版首发目标

- 世界地图提供统一目录内国家和地区的可选择入口、基础资料与内容状态；目录和地图名称采用同一口径。
- **二十个深度国家包**，覆盖亚洲、欧洲、非洲、北美洲、南美洲与大洋洲。
- **至少一百处地标、至少一百六十篇主题文章、至少一百六十张实景照片。** 数量由二十个国家包的最低标准推导，质量审核优先。
- 八个跨国专题，加一个南极洲专题；前述八个跨国专题各关联至少三个国家。
- 地图、阅读、搜索、朗读、收藏、续读、离线内容和本机记录构成完整可用流程。
- 三个代表国家先作为设计与内容样板，用于验证栏目结构和使用体验；样板阶段不等于完整新版首发。

## 6. 核心验收情境

1. 孩子从世界地图找到一个国家，知道它在哪里，并进入这个国家的完整介绍；小面积国家也能通过搜索找到。
2. 孩子看见一处风景，能放大照片、了解它如何形成、在地图上定位，并回到原文章。
3. 孩子读完一个主题，能用自己的话说出一两个特点；有不懂的词可以就地查看解释。
4. 孩子退出应用后再次打开，可以继续阅读；收藏和笔记仍在。
5. 无网络时，已安装内容可阅读和搜索；未下载内容有明确状态和返回路径。
6. 国家尚无深度包时，孩子能读到现有基础资料；目录不把空壳页面标成完整百科。
7. 阅读进度、收藏、下载、问答和搜索都有加载、空结果、失败与恢复状态。
8. 同一篇内容在手机、横屏平板和系统大字体下都可完整使用。

## 7. 后续设计顺序

1. 根据本功能清单确定首发范围，形成页面清单与导航关系。
2. 重新探索视觉方向，用发现页、地图页、国家页和文章页四个关键页面比较整体风格。
3. 细化地图交互和一个完整国家的阅读流程，再扩展到其余页面与所有状态。
4. 使用图片生成和 Stitch 制作视觉素材与页面设计，区分设计稿和可实施规范。
5. 按新信息结构与页面规范开展 Flutter 重构，并同步制作和审核内容包。

本阶段不确定配色、字体、卡片样式、插画角色或动画风格，也不将旧页面结构作为新设计的前提。
