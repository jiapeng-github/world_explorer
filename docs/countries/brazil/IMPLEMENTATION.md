# 巴西模块实施记录

更新日期：2026-11-12。设计基线：`design-board.png`。主题“从河流走向多彩大地”；浅色界面、深海蓝文字、橙色操作与绿色生态辅助色。实现使用可核验的实拍与GIS，设计图中的虚构景观、生态轮廓没有充当事实资料。

## 页面与交互

- 首页：里约全景、国家名片、三条照片路线、双问题、继续阅读、收藏与“我的巴西发现”。简介折叠后主入口优先可见。
- 目录：森林/鹦鹉/瀑布三图拼接、十个照片栏目卡、全国地图入口。没有重复展示旧版占位地点卡。
- 阅读：正文、词汇、图注与来源、听讲、收藏、笔记、对应地点和证据题；图片可以查看来源，不把照片当成实时记录。
- 两河交汇：NASA卫星影像、原创混合关系示意、理解题；答对后跳转马瑙斯局部水系图。
- 潘塔纳尔：水豚实拍、同一地形下较湿/较干水位切换、水/植物/动物关系说明、证据题与生态图跳转。示意不冒充两张同机位季节监测照片。
- 地点：12处重点地点有可点击照片观察点，支持关联阅读、地图、图库与观察笔记。
- 视觉节拍：四拍播放、停止、手动回应；离开页面取消计时器。系统减少动画设置下改为手动下一拍，不评分点击延迟，不冒充真实弗雷沃乐曲。
- 笔记：三栏可任选一栏开始，保存后进入真实“我的巴西发现”；重新载入数据库验证记录存在。
- 平板延续同一内容结构，自适应宽度；320像素、1.5倍文字下检查全部新版阅读、地点和任务入口。

## 真实地图数据

`assets/atlas/brazil-biomes.geojson`由IBGE **2019版**`Biomas_250mil.zip`生成，六个陆地生物群系：亚马孙、塞拉多、卡廷加、大西洋森林、潘塔纳尔、潘帕。包含源版本、1:250000源比例尺、归档SHA-256、处理方法与链接。SIRGAS 2000（EPSG:4674）转换为WGS84；源坐标对齐后采用共享边界简化，保留多面与内部环。UI显示“IBGE 2019”，明确生态区不等于现存植被覆盖。

生成工具：`tool/maps/build_brazil_biomes.py`，依赖Shapely 2.1+、pyproj。源归档：
https://geoftp.ibge.gov.br/informacoes_ambientais/estudos_ambientais/biomas/vetores/Biomas_250mil.zip

`brazil-rivers.geojson`保留Natural Earth 1:10m亚马孙河与内格罗河真实线段；没有用手绘线填补源数据缺口。马瑙斯深链接使用独立聚焦范围，图层切换保持相机，复位返回全国范围。生态区支持点击区域内部，非仅标签点。此地图是学习地图，不提供实时水色、水深或现场导航。

## 内容与素材溯源

正文源文件：`tool/content/sources/brazil_expanded.txt`、`brazil_rivers.txt`、`brazil_city.txt`。编译器：`tool/content/author_brazil.py`；内容与素材清单分别位于`tool/content/editorial/brazil.json`、`brazil_assets.json`。

事实材料采用IBGE、NASA、UNESCO、IPHAN、巴西议会档案、FAO、Kew及动物园的相关资料。文章与国家保留URL和核查日期；`sourceChecked`表示来源核对，不宣称独立人工编辑审核。人口等动态统计没有无年份填入。

媒体标注作者、许可链接、拍摄日期或来源的日期说明、尺寸、SHA-256和处理方式。NASA两河影像摄于2012-06-17，巴西利亚夜景摄于2011-01-08，里约全景摄于2006-02-04。实拍可以不同于生成效果图，不能将生成图中的景物当成实地证据。可可豆干燥比较照片明确拍摄于加纳，并在正文说明不是巴西产地；潘塔纳尔鹦鹉照片没有作为阿纳维利亚纳斯物种证据。木薯正文不提供儿童自行加工指导。

## 复现

日常重新编译无需联网：

```sh
python3 tool/content/author_brazil.py
python3 tool/content/build_catalog.py
python3 tool/content/validate_catalog.py
python3 tool/content/brazil_validation.py
python3 -m unittest discover -s tool/content -p 'test_*.py'
flutter --no-version-check analyze --no-pub
flutter --no-version-check test --no-pub test/brazil_experience_test.dart
```

重建最初河流/巴西利亚4篇源稿时，先运行`author_brazil_rivers.py`与`author_brazil_city.py`，再运行上述完整编译器，以恢复新版栏目与路线。编译器的重复运行已验证字节一致。

截图复现：

```sh
flutter --no-version-check test --no-pub --dart-define=CAPTURE_BRAZIL=true test/brazil_experience_test.dart
```

截图在`implemented/390/`和`implemented/1194/`。已检查首页、照片目录、四图层中的生态图、两河阅读、湿地互动、地点、历史时间线、任务、发现与三栏观察页面。
