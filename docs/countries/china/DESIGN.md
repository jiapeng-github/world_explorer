## 1. 要做成什么样

把中国做成第一个完整的示范国家。孩子打开后，先被山川和真实生活吸引，再通过地图、照片、短文和观察任务理解它们之间的联系。

核心表达：**从高山到大海，发现中国。**

三条探索主线共用内容，不复制文章：

| 主线 | 孩子的问题 | 连接的内容 | 一次探索的收获 |
| --- | --- | --- | --- |
| 山河 | 为什么有的地方高，有的地方低？ | 地势 → 河流 → 九寨沟 / 栖息地 | 能用地图或照片指出一种地理联系 |
| 生活 | 一条河怎样影响人们的生活？ | 大运河 → 城镇与交通 → 食物与交流 | 能举一个地方生活的例子，并知道它不代表所有人 |
| 文明 | 留下的东西能告诉我们什么？ | 长城 → 历史线索 → 剪纸、节日与手艺 | 能分清自己看见的证据、猜想和还想问的问题 |

这些是可随时切换的阅读建议。内容全部开放，不以答题、签到或收集积分解锁。

## 3. 信息架构

保留既有栏目键，避免破坏路由、收藏和旧记录。三条探索主线是面向孩子的入口，十栏目是完整检索目录。

| 栏目键 | 界面名称 | 内容职责 |
| --- | --- | --- |
| overview | 国家名片 | 在世界的位置、认识地图的方法、如何开始探索 |
| geography | 地理与气候 | 地势、河流、气候和地理差异 |
| people | 人们与语言 | 地方生活、语言文字、尊重差异 |
| daily | 日常生活 | 交通、房屋、城镇和日常活动 |
| food | 饮食与物产 | 食物来源、加工手艺、地域与交流 |
| culture | 艺术与节日 | 剪纸、节日、器物和手艺传承 |
| landmarks | 城市与地标 | 建筑、城市空间、真实风景观察 |
| nature | 动物与生态 | 动物、栖息地、生态联系和保护 |
| history | 历史故事 | 用物证认识不同年代，区分历史与传说 |
| questions | 有趣问题 | 跨栏目读图、比较与观察方法 |

页面路径：百科 / 地图 / 搜索 → 中国概览 → 主线或栏目 → 文章 / 地点 → 读图或观察 → 记下发现 → 返回原文或继续探索。

一个国家、栏目、文章都只有一个稳定 ID。同一篇文章可从多个地方进入，阅读进度只记一份。

## 4. 中国概览（CN01）

手机参考 430×932，窄屏验收 390 宽；平板不把手机页面等比拉大。

从上至下：

1. **封面**：金山岭长城实景，首屏约 32%–36% 高度。标题“中国 / CHINA”，副标题“从高山到大海，发现中国”；返回与收藏覆盖在有足够对比的区域。图片不能盖住重要文字。
2. **一句认识**：“沿着山川、生活与文明，读懂这片土地。”展开后约 100 字，介绍自然与人文的多样性。
3. **三项小资料**：位置“亚洲”、首都“北京”、货币“人民币”。“更多资料”再放面积、语言文字等；人口等时变数字只有核对统计日期后才出现，不在首页用大数字抢注意。
4. **三个图片入口**：“山河”“生活”“文明”；每个点开对应短路线目录。
5. **问题入口**：每次稳定显示 2 个编辑精选问题；不自动轮播。点击直接读对应文章。
6. **完整目录**：先列 6 个常用栏目，展开全部 10 个。标题、图标、可点击状态一致。空栏目在正式目录隐藏。
7. **地图与地点**：一张静态地图预览 +“在地图上看看”，其后展示 3 张精选地点卡片；点击明确进入地图或地点页。
8. **历史线索预览**：2 条内容节点，进入完整时间线；末尾资料来源入口。

固定底部按钮：首次“从山河开始”，有未完成阅读时“继续阅读：{短标题}”；另提供可见的“换个主题”入口，不强迫续读。底部不叠加全局四栏导航。

收藏仅表示收藏国家；打开页面只记访问，不算读完全部内容。

主线建议顺序：

| 主线 | 第一站 | 第二站 | 第三站 | 结束动作 |
| --- | --- | --- | --- | --- |
| 山河 | 中国地势 `china-geography` | 长江水系 `china-river-journey` | 九寨沟 `china-jiuzhaigou` / 熊猫 `china-nature` | 在图上指出一个联系 |

单站建议 3–5 分钟，完整小路线建议 10–15 分钟，可随时退出。时长是编辑估计，不显示倒计时，不把实际用时当能力评分。

## 6. 中国探索地图（CN03 / CN04）

### 6.1 取景与内容层

进入时完整取景中国相关地理范围，为侧栏/底部面板留边距。国家/省级地理资产使用经核对的数据与图示，正确呈现岛屿和必要附图；不从生图稿描摹边界。已有世界地图资产只能作为当前基础，不能宣称已具备中国省级地图精度。

| 图层 | 默认展示 | 点击行为 | 制作范围 |
| --- | --- | --- | --- |
| 地形 | 地形晕渲，少量高原/平原标签与图例 | 点开“高原”等短释义或相关文章 | 第一版：地势观察；省级细节后续补充 |
| 河流 | 长江、黄河；选中时提高对比 | 河流整段高亮，分源头/中游观察点/入海口 | 真实折线；不能用直线连接几个点假扮河道 |
| 地标 | 已有内容的 12 个点，密集时聚合 | 开底部卡片或平板侧栏 | 建成一处上线一处，数量取已发布数据 |
| 城市 | 首都与内容涉及城市 | 关联已有文章或地点 | 不承诺街道、路线导航和实时定位 |

主控制为“地形 / 河流 / 地标”，城市标签按缩放层级辅助显示。首版不一次堆出行政、天气、交通等大量开关。

状态：未选中 → 点选对象 → 内容卡片 → 打开详情。换图层保留镜头；点空白处收起对象卡片；“显示中国全图”可恢复初始镜头。

### 6.2 精致感如何落地

- 地形底色柔和，河流用清楚的蓝线，选中标记用橙色并附白色描边；标签用深色文字与浅色衬底。
- 国家/省界、河流、标注层独立；边界与河流不使用同一种线型。海拔图例说明色阶，不将绿色一概解释为森林。
- 同屏重点标签手机约 6–10 个、平板约 10–16 个，实际由碰撞检测决定；选中对象优先，不能让文字盖住定位点。
- 点标记视觉约 14–20，但交互区至少 48；聚合数字代表地点数，不是已完成数量。
- 点击细河流允许屏幕容差；相邻对象难区分时出候选列表。无障碍提供同步地点列表，不依赖拖动与颜色作答。
- 示意“三级阶梯”使用单独剖面图，并写“地势示意”；它不是地图的真实海拔剖切测量结果。
- 不自动追踪设备位置，不要求孩子分享住址；搜索只在百科地点和内容中进行。

### 6.3 面板布局

手机面板：约 25%/50%/85% 三挡，分别为标题摘要、图片动作、详情列表；进入地点文章保留镜头与图层。平板 ≥1024：地图约 65%，侧栏 320–380 宽；地图 fitBounds 扣除侧栏范围。600–1023 宽按空间切换底部面板。

未研发内容继续遵守用户已确定规则：百科目录不展示；地图上若保留该国家或基础地理对象，按钮为**“即将上线”且不可点击**。不能把“未研发”误当成“未下载”。没有内容的城市只是地图地名，不伪装成可进入的地标卡片。

## 7. 阅读与地理互动（CN05）

每篇采用统一结构：一个主问题 → 一张能帮助回答问题的图 → 4–6 个短段落 → 一次观察或理解 → 一句结论 → 进一步提问与来源。

| 内容元素 | 规格 |
| --- | --- |
| 主标题 | 手机 28–32，最多 3 行；标题必须与正文实际内容一致 |
| 正文 | 默认 18，行高约 1.65；每段约 70–120 字，单篇基础层 450–650 字为编辑目标 |
| 深入层 | 可展开“再想一步”，约 100–180 字；不阻塞主阅读 |
| 难词 | 每篇 1 个核心术语 + 1–3 个辅助难词，点击解释与按需拼音；不默认给整篇正文堆拼音 |
| 图片 | 有图注、位置/对象、作者与许可；生成示意图标注示意，不称实拍 |
| 朗读 | 复用现有 TTS；段落定位、播放/暂停、缺语音提示。无保证时不画逐字高亮或精确秒数 |
| 工具栏 | 目录、听讲解、收藏、笔记；固定底部，与正文安全区域错开 |

示例：《中国的地势有什么不同？》先读剖面图，再寻找“西高东低”的含义，最后问“这是否表示每一条河都向东流？”。答案必须解释“整体概括与局部例外”，不让孩子只记口号。

读图互动支持点选“西部/东部”，也支持拖动观察，但拖动不能成为唯一操作方式。提交后显示简短说明和“回到这一段”；错误答案不震动惩罚，不扣分，可重新观察。

## 8. 地点与风景（CN06）

图集每处建议 3 张：环境全景、代表细节、人/自然关系。图集中的具体照片位置必须与地图锚点吻合；线性/区域遗产使用观察点说明，不将一张照片代表整个遗产。

## 9. 历史与文化（CN07 / CN08）

历史入口先让孩子看器物、建筑、水道、手艺，再认识时间。默认“看线索”；“看时间”展开年代，并解释“公元前/公元”。

首屏四组线索：“秦汉 · 城墙与道路”“隋唐 · 水路与往来”“宋元明清 · 手艺与城市”“今天 · 研究与保护”。这四组是精选故事入口，**不是完整朝代史或完整历史时间线**；页面必须写“精选线索”，不能用等间距节点暗示相等时间长度。

每个节点有对象图、年代范围、两句故事和“证据来自哪里”。民间传说单独注明“传说”，不能作为考古或历史事实。年代排序题不要求死记全套朝代。

剪纸篇展示纸张、作品细节和一个对称图样。只把“对折—剪形—展开”作为一种示范，不声称所有剪纸都如此制作；正式图稿使用三步一致的同一图案，且展开结果与剪口对应。端午与茶分别有独立内容，不用标题替换掩盖重复正文。

## 10. 日常生活与生态（CN09 / CN10）

生活页用明确地方的例子讲交通、房屋、食物和语言，不以“所有中国人都……”概括。照片旁给地点与情境；城市与乡村不是先进/落后的评分。

“米和面，从哪里来？”是设计图中 `china-food-market` 的候选入口短标题，正式标题为“一顿饭的食物从哪里来？”，不是第 31 篇文章。它介绍原料、加工与交流，不把南米北面画成没有例外的硬边界。“一片茶叶”讲种植、加工与待客文化；孩子参与的是观察原料与工具，不设置喝茶挑战。语言内容尊重普通话、方言与其他语言，声音素材需要真实来源，未制作时不显示假播放按钮。

生态页围绕“动物需要什么样的家”。熊猫照片配竹林、山地森林等具体场景；将食物、水源、活动空间放在同一幅关系图中。若使用圈养照片，应在图注说明，不能冒充野外拍摄。

熊猫页不使用过时种群数量或保护等级做装饰数字。保护关心栖息地的整体联系，不能设计“把动物抓回家照顾”之类任务。

## 11. 探索与发现笔记（CN11 / CN12）

24 道封闭题目标分配：12 道选择/判断、6 道地图定位、6 道照片/图示观察。另有 6 个开放任务：山河、长城、运河、食物、手艺、动物家园各 1 个。详见内容规划对应关系，避免为凑题数重复提问。

题目状态：未选择 → 已选择 → 已提交 → 解释 → 回看依据 / 下一站。任何时候可返回。地图作答未命中时不自动判错；点选后先标记对象，再由“确认”提交。

开放观察不评“正确率”。模板为“我看见…… / 我猜想…… / 我还想知道……”，三项任选填写；保存一条真实笔记即可。初始为空，示例只能作为明确标注的帮助文字，不能预写进用户记录。

探索回顾显示读过的文章、看过的地点、保存的笔记，分别计数。取消收藏不删除阅读记录；删除笔记有撤销。没有笔记时显示“写下你的第一个发现”。不显示“已学会中国 100%”，不将浏览等同于理解。

## 13. 数据与组件增量

现有生产模型没有完整的类型化内容块和审校状态驱动发布，不将文档中的规划字段当作已实现能力。

| 增量 | 必要字段 / 行为 |
| --- | --- |
| CountryEditorial | countryId、intro、heroMediaId、journeyIds、sectionIntro、featuredPlaceIds |
| Journey | id、title、orderedArticleIds / placeIds、suggestedMinutes；不存复制正文 |
| TypedBlock | paragraph / image / diagram / mapReference / observation / timeline；每块稳定 id |
| Article 修订 | sources 按具体段落关联；glossary 多词；evidenceBlockIds；reviewStatus、revision |
| MapFeature | geometryRef、kind、label、bounds、anchor、linkedContentIds、dataSource；经纬度统一顺序 |
| LandmarkHotspot | mediaId、归一化 x/y、label、explanation；文字列表提供同等信息 |
| TimelineNode | id、periodLabel、sortStart、sortEnd、evidence、articleIds；表示真实年代与约数 |
| Availability | draft / inReview / published；与安装状态独立；目录筛选 published |

建议组件：CountryHero、FactStrip、JourneyTile、SectionDirectory、AtlasFeatureSheet、ObservationPrompt、PhotoHotspotViewer、EvidenceTimeline、CountryDiscoverySummary。使用数据驱动通用组件，避免把中国内容硬编码到通用 CountryScreen 的条件分支里。

源稿继续放 `tool/content/editorial/china.json` 或其分片目录；生成到 `assets/atlas/catalog.json`。当前 build_catalog.py 是 append 流程，覆盖旧文章前必须改为按 ID 合并并拒绝意外重复，否则在补充源稿中添加同名文章会生成重复 ID。保留 7 个既有 articleId 和 3 个 placeId。

正文语义变化时不能盲目沿用旧 blockId 位置。对熊猫/剪纸等重写篇提供旧→新段落映射，无法映射则回到新篇首并保留旧笔记标题快照；不把旧版完成状态自动当作新版已读。用户记录与内容包修订分开迁移。

## 14. 视觉与响应式规格

延续已认可的现代地理图鉴风格，**不因新 Logo 的立体插画风格而改变正文界面方向**。

| 项目 | 规格 |
| --- | --- |
| 色彩 | 白底 / #F4F7FB，深海蓝 #12395B，主文字 #12243A，橙 #FF9A3D |
| 留白 | 手机左右 20–24，段落间 16–24，模块间 32；平板外边距 32–48 |
| 圆角 | 图片/卡片 16，按钮 12；正文段落不套一层层卡片 |
| 动作 | 最小点击区 48×48，主按钮高 52–56；橙底配深色字 |
| 图片 | 真实风景与生活为主；历史、自然各有自己的素材，不共用长城封面 |
| 手机 | 单列阅读，目录/地图详情底部面板，固定工具栏不挡正文 |
| 平板 | 概览可双栏；阅读主栏最多约 680 宽，目录 220–260；地图单独分栏 |
| 大字号 | 文字允许换行，双列改一列；不缩小正文硬塞原布局 |
| 动效 | 点击约 150–200ms，地图聚焦约 450–650ms；减少动态效果时取消长镜头移动 |

图稿是视觉基准；正式实现使用真实控件、授权素材和审核后的地图数据。生图文字、地图位置或图形逻辑如与本文冲突，以校核后的规格为准，并在视觉交接中登记差异。

## 16. 实施顺序与验收

本轮止于设计交付。后续开发按以下顺序执行，不以生成了设计稿代替实现完成。

1. **内容修复与基础编排**：修复 4 项错位；完成首批约 12 篇及对应真实媒体；概览、栏目与详情使用同一内容索引，只展示已发布内容。
2. **地图与阅读闭环**：中国地图取景、河流/地标图层、地图到文章返回、剖面图、照片观察、题目证据回读。
3. **深度内容完成**：扩展到 30 篇、12 个地点、36 张照片 + 6 张示意图、24 道题 + 6 个开放任务；完成历史、生活、生态与发现回顾。
4. **手机和平板验证**：390 / 430 / 1024 / 1194 宽度，大字号、横竖屏、断网和实际 Android 平板操作；再考虑正式发布。

验收清单：

- 文章标题、摘要、正文、主图、来源、理解题彼此对应；任何一项错位不能发布。
- 所有栏目拥有独立主内容；推荐可以复用，但统计按唯一 ID 去重。
- 每处地点有可核对的地图锚点与完整照片来源；缺授权素材不显示为已完成。
- 未研发国家仍在百科隐藏，地图按钮禁用；设计更新不能回退已有行为。
- 阅读 → 地图 → 地点 → 返回原文准确；退出重开恢复真实进度，收藏与笔记不丢失。
- 题目答案能定位到内容依据；地图目标只在有效地理对象上判定，不使用屏幕硬编码坐标。
- 390 宽与放大字号没有文字溢出、主按钮遮挡或图例不可读；地图同时有列表路径。
- 生产中没有演示笔记、假进度、未制作的播放按钮、图库中的生成实拍冒名素材。
