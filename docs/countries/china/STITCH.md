## 导出与使用边界

Stitch 返回了两页 HTML 的 `downloadUrl` 和截图地址，可在上述项目中继续编辑或下载。链接可能需要登录、有效会话或后续刷新；资源名称与 screen ID 已保存，链接失效时可以通过 `get_screen` 重新查询。

本轮没有把远程截图下载到工程，也没有将 Stitch HTML 当作 Flutter 代码接入。Stitch 结构稿与主设计生图互补，Flutter 开发需实现真实组件、数据、导航和触控行为。

需要在开发时校正的明确差异：

1. Stitch 返回的画板尺寸与请求不一致，地图页还被标成 DESKTOP。应按 390/430 手机和 1194×834 平板重新适配，不能把返回截图缩放后当作字号与点击面积验收。
2. Stitch 的自动 Material 色板含 `#f8f9ff` 等衍生色。工程使用 `#F4F7FB/#FFFFFF/#12243A/#12395B/#265F91/#FF9A3D` 等原 token，不直接覆盖现有 AtlasTheme。
3. 地图背景和河流路径属于概念示意，尚未完成地理数据核验；须换成工程核验后的地形、水系与地理对象。生成说明中的“准确”“真实”等是工具自述，不是实际验证结论。
4. 九寨沟等图像是生成稿素材，不代表实拍或授权已完成。正式正文采用逐图核对的照片与图片许可。
5. 主页生成过程补写了“烽火台建在最高耸山脊”等问题，不能直接采用为事实。实施时使用经内容审核的中性观察题，例如“你在照片里看到了哪些顺着山势变化的地方？”
6. 浏览器打开 Stitch 项目预览超时，本轮确认的是工具返回的页面状态和元数据，未声称完成浏览器视觉验收。
