# 德国 · 沿着河流发现世界

设计1.0 · 2026-11-11 · 已确认并进入Flutter实现，交付与差异见[实现记录](IMPLEMENTATION.md)。延续法国现代地理图鉴，以生图效果图作为视觉基线，不使用Stitch。

## 产品范围
面向8岁儿童，十栏目30篇、12地点、24闭合题（12选择/6定位/6观察）、6开放观察、3阅读路线。保留国家ID deu 与已有收藏笔记。内容完成前不将德国标记已上线。

三条路线：river-city 河流与城市（莱茵河→汉堡港→城市街道）；forest-coast 森林与海岸（倒木→瓦登海→阿尔卑斯）；objects-time 物件里的时间（活字→印刷史→1989/1990）。全部注明“阅读顺序，不是交通路线”。

## 地图
北向上，德国全境及岛屿；邻国淡化作参照，不把跨境河流、湖泊或整个阿尔卑斯涂成德国所有。首发莱茵河、易北河、多瑙河，科布伦茨补摩泽尔河汇合细节。真实点线面数据，默认全境相机；16州仅在有许可边界数据时加入行政层，不用AI绘图替代GIS。

输入WGS84，建议ETRS89/LAEA Europe EPSG:3035，最终投影参数写入manifest。地形教学区域与行政边界采用不同图例；劳西茨文化范围注明近似及跨界性质。世界图沿用现有投影。手机抽屉25/50/85%，平板右栏320–360dp；缩放、切层、选择保存状态，地点点击区至少48dp，河线命中容差14dp。搜索支持Deutschland/Germany/德国、Köln/Cologne/科隆、München/Munich/慕尼黑等。错误链接回到有效范围或地点列表；缺地图可读文字列表。点选不累计访问，进入详情才计数。

## 视觉与交互
390×844基准、20dp边距、8dp间隔系统。白底与#F4F7FB，深海蓝#12395B、橙色#FF9A3D。实景主图260–280dp，卡片16dp圆角，图片12–16dp。标题28/36，正文18/30，图注14/21，CTA高56dp。沿用现有App标识，不使用生成图中的临时图标替换品牌。

只有文章页显示目录/听讲解/收藏/笔记。地图手机用发现/地图/百科/我的底栏，平板用左栏；国家页、目录、地点、任务、发现、笔记不加入阅读工具栏。设计中的照片、地图、档案为概念占位，正式素材需事实及许可核验。

闭合题未选禁用确认，选择可改、提交保存、答错显示解释与重试、不扣分。证据回跳本篇block。开放题至少一项非空可保存，保存中防重复提交，失败保留输入。支持大字号和屏幕阅读，图解提供文字等价说明。
