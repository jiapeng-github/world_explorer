# 埃及 · 从尼罗河看埃及

2026-11-07 · Flutter「世界大百科」国家深度设计 · 设计规格 1.0

面向约 8 岁读者。孩子可以先在地图上找到尼罗河和地中海，再用照片理解水、土地与今天的生活有什么联系，最后带走一个自己还能继续查的问题。沿用中国模块已经建立的浅色图鉴、深海蓝、橙色和大幅实景体系。

## 2. 入口、路线与阅读节奏

主入口为「百科 → 埃及」。发现页推荐、搜索结果、地图详情也能进入同一篇文章或地点。子页以本地返回和上下文操作为主。世界地图仍使用现有四个主入口。尚未研发的国家沿用百科隐藏、地图显示禁用的「即将上线」规则。国家卡片沿用无「离线百科」标签的样式。

| 主线 | 三站阅读顺序 | 带走的发现 |
| --- | --- | --- |
| 沿着尼罗河 · nile | 尼罗河流向哪里？ → 今天的埃及人怎样生活？ → 河口为什么像一把扇子？ | 用方向、河道和照片说出河谷到三角洲的变化 |
| 走进今天 · today | 开罗的两种街景 → 一碗库沙里 → 住在河上的岛怎么到对岸 | 看见同一国家里不同城市、家庭和场景的生活 |
| 追寻文明 · civilization | 金字塔留下的线索 → 纸莎草如何成为书写材料 → 石头神庙怎样搬家 | 区分看得见的遗物、历史解释和还想查的事 |

每站约 3–5 分钟，以文章数据为准。首页首次显示「从尼罗河开始」，有未完成阅读则显示「继续阅读」，下方附文章名和「换个主题」。由孩子决定先看哪站，答题和写笔记都可以跳过。探索路线用站点序号表示阅读顺序，地图上不绘制旅游线路。

典型操作从概览进入「沿着尼罗河」，在读图中点选「朝地中海」，然后进入地图的水系层，选中三角洲，查看同位置卫星图，回到文章时继续读原段。孩子可在地点或文章写观察，再到「我的埃及发现」回看自己的记录。每一步都有明确返回，练习反馈提供「回到证据」和「继续探索」。

### 3.1 概览与目录

1. 手机首图高约 286–320dp，用吉萨广角，标题「埃及 / EGYPT」，副标题「从尼罗河看埃及」。返回、收藏与文字置于有足够对比的遮罩或独立区域。图片说明标明拍摄主体。
2. 引语「沿着水、城市和石头留下的线索去发现。」小资料卡显示「非洲东北部 / 开罗 / 埃及镑」。展开时补充主要国土的位置、西奈半岛在亚洲、官方语言阿拉伯语、邻近海域。首屏资料由固定事实字段提供，不从显示字符串猜货币代码。位置与国情依据[埃及国家信息服务](https://sis.gov.eg/en/egypt/basic-information/)。
3. 路线卡用三张不同图。尼罗河用河谷或阿斯旺，现代生活用开罗沿河城市，文明用卡纳克柱廊。编辑问题固定选择「尼罗河流向哪里？」「金字塔留下了哪些线索？」。三处精选地点为吉萨、尼罗河三角洲、阿布辛拜勒。
4. 目录采用现有十栏目顺序，390/430 默认两列，1.5 倍字号或容不下完整标题时降为单列。卡片完整可点，标题完整换行。切到目录再返回保留滚动位置。

### 3.2 埃及地图

**首屏默认**。由概览打开时显示埃及全图和「地点列表」，初始不自动跳入题目。由目录的「下一站，去三角洲」或其他详情打开时高亮来路对象。平板右栏默认展示选中对象或候选地点。手机默认折叠面板，选点后展开到半高。地图采用北向，复位含地中海岸、三角洲、埃及主要国土、西奈、红海北部和阿布辛拜勒，并允许平移观察邻近区域。南侧河道在资料范围之外使用连续标识，避免被读成尼罗河发源于埃及。

| 图层 | 显示 | 可操作对象 |
| --- | --- | --- |
| 地形 | 真实地形底图、河谷与沙漠、必要海岸轮廓、北箭头与来源 | 区域观察标签和相关地貌解释，少量城市提示 |
| 水系 | 尼罗河、三角洲、地中海、红海北部、纳赛尔湖、苏伊士运河。天然河与人工运河用不同线型 | 稳定 featureId、实际河线容差选取、经核对的区域观察锚点，三角洲可打开卫星图 |
| 地点 | 12 处已收录地点，分类和聚合数量。高密度处展开放大 | 当前地点、照片、说明、查看地点。吉萨/开罗、阿斯旺/菲莱、卡纳克/王家谷用候选列表消除误触 |

搜索支持「三角洲／尼罗河／吉萨／开罗／阿布辛贝勒／阿布辛拜勒」等名称及别名。只展示地图内条目，支持键盘和读屏。对象点按后橙色加描边，同时显示选中文字。面板用标题/摘要/查看动作三个层级，手机约 25%/50%/85% 三挡并可用按钮控制，平板可用宽度满足时约 65% 地图、350dp 详情。缩放、平移和改变图层保留视野，返回时恢复选中 ID、图层、中心、缩放及面板状态。空白点击清选点。全图复位按钮标「显示埃及全图」。地点与图层不足时优先名单与读图来源。

**数据策略**。现有底图可以继续使用，埃及水系需要新资产和可命中的数据源。首选 Natural Earth 1:10m river/lake centerlines，以原始记录识别主干并保留原段、来源、数据版本和 SHA-256。用 1:50m 海岸和带日期 NASA 影像对照。江河、湖泊、人工水道使用不同类型。核对罗塞塔与达米埃塔两汊，有可用且许可明确的线时分别显示。资料不足时显示区域代表点和卫星影像的标注对照，学习题仍可用真实区域点或两岸点作答。苏伊士运河同样在可核对线形与可用授权齐备时显示线段，简化版用具名地理观察点。三角洲表示区域，不用中心点伪装成精确河口。行政轮廓、河道和站点均需来源核验。参见 [Natural Earth 水系数据](https://www.naturalearthdata.com/downloads/10m-physical-vectors/10m-rivers-lake-centerlines/)、[NASA 尼罗河影像](https://science.nasa.gov/photojournal/the-nile/) 和 [苏伊士运河管理局](https://www.suezcanal.gov.eg/English/About/SuezCanal/Pages/AboutSuezCanal.aspx)。

**图层与练习分开**。埃及全图练习只允许题目候选 `featureId`。世界定位题 `egypt-location` 用世界尺度，局部两岸题按候选范围适配。未命中地图不改变答案，文字单选同步高亮地图且可独立提交。地图题不把橙色、默认选点或跳转中心作为答案暗示。热区目标 ≥48dp，细线使用屏幕像素距离而非经纬度阈值。

预留地理对象 ID `egypt-nile`、`egypt-delta-rosetta`、`egypt-delta-damietta`、`egypt-lake-nasser`、`egypt-suez-waterway`、`egypt-mediterranean`、`egypt-red-sea`。地点选取沿用各自 Place ID。阅读中的「在地图上看看」传入 `?country=egypt&layer=water&feature=egypt-nile`，地点页传入 `place`。存在明确来路时返回上一页及原阅读位置。

### 3.3 阅读、照片与历史

每篇 4–6 段，每段约 70–130 个汉字，正文建议 450–650 字，手机 18dp、行高约 1.65。主题词 1 个加 1–3 个辅助词，必要时给发音和外文。段落标题用于目录和反馈锚点。图片有主题、地点/馆藏、日期可查时的时间信息，以及署名和许可。证据图像的拍摄位置、裁切与正文提问要一致。平板加目录侧栏，正文宽不超过约 680dp。手机读图先给结论所需的小图与文字说明，底部工具栏保持「目录 / 听讲解 / 收藏 / 笔记」。朗读依赖已可用的中文系统语音，文字阅读不依赖声音。

吉萨地点详情放大照片时同步放大编号热点，原照片坐标保存为 `x/y` 归一化值。同一热点也在图下用编号和文字展示，点击热点或文字均显示同一段说明。仅选择照片确实能看到的石块接缝和轮廓，不用近景标记覆盖全景别处。用未经裁切的主图检查点位后，为不同显示裁切单独做坐标映射。阿布辛拜勒说明眼前是现址，迁建前后只有在照片授权及年代地点核实后才作图对照。位置区分古迹现址、展示馆藏地点和拍摄地。

历史线索用卡片表达，卡片间距不对应年代比例。「看线索」展示照片、对象和问题，「看时间」补充时期、时间解释及来源。 

| 节点 | 标注 | 证据例子 |
| --- | --- | --- |
| 吉萨金字塔 | 古王国时期 | 石块、陵墓群与周边建筑一起提供线索 |
| 底比斯的神庙 | 新王国时期的扩建 | 卡纳克柱廊和两岸不同类型的遗迹 |
| 开罗历史街区 | 10 世纪起 | 街道、旧建筑与今天的城区 |
| 努比亚遗址救援 | 1960—1980 年国际行动 | 阿布辛拜勒与菲莱的迁建、记录和保护 |

时间资料按 UNESCO 的[吉萨遗址](https://whc.unesco.org/en/list/86/)、[底比斯遗址](https://whc.unesco.org/en/list/87/)、[开罗历史城区](https://whc.unesco.org/en/list/89/)与[努比亚国际救援](https://whc.unesco.org/en/list/88/)核对。古代建筑时期与现代救援年份分别标注。标题不把一种建造假说当定论。具体材料、器物、语言的用词在内容清单中逐篇约束。

### 3.4 任务、反馈和发现

| 状态 | 画面与行为 |
| --- | --- |
| 选答前 | 题目与图，单选区域可换行。「确认」禁用。可展开提示、可跳过 |
| 选择后 | 选中描边和文本同时出现。仍可改选。「确认」可用 |
| 提交后 | 显示依据和解释，答错提示还可怎样看。错误状态允许再试。「回到证据」滚到本篇对应块并高亮，返回保留本题反馈 |
| 开放观察空态 | 阅读一张图或一个地点，三格初始为空，保存按钮禁用，任意一格填有效文字后可保存，无得分 |
| 编辑与保存 | 自动恢复同一任务草稿，键盘不挡保存。保存时禁止重复提交。失败保留输入，显示可重试。成功生成一条用户记录 |
| 发现页空态 | 已读 0、看过 0、记下 0。「从一条观察开始」打开任务或建议文章 |
| 发现页有记录 | 区分读完的篇数、去过页面的地点数和实际笔记数，点击可回来源。笔记支持编辑、删除撤销 |

闭合题每篇只绑定一项核心活动，其他读图点按不新增题目计数。开放任务的三段标题为「我看见」「我猜想」「我还想知道」。由照片热点进入时，带上实体 ID 和选中材料，三格仍留给孩子自己写。所有计数按稳定 ID 去重。「看过一处」指浏览 App 地点详情，不表示到访实地。笔记示例仅用于界面稿。

设计数据合同沿用既有 `editorial.journeys`、`sections`、`timeline`、`featuredPlaceIds`、`article.activity`、`article.exerciseId`、`evidenceBlockIds` 和 `place.hotspots`。建议新增 `editorial.startJourneyId`、`startLabel`、`questionArticleIds`、`featuredDirectoryPlaceId`、`factOverrides`、地图配置和练习 `mapScope`。观察题可增可选 `mediaIds` 支持双图、`diagramStep` 指定纸莎草题画面、`hotspotOptions` 指定可点击的照片候选点，保留已有单图和文本选项的回退。章节仍以全局 10 个键为准。新增媒体引用也须进入打包收集与 ID 重映射。

数据验收以实际目录为准。每个栏目恰有 3 个独立主篇，跨栏推荐和路线引用单列。每个图解或热点只引用已存在的媒体/地理特征。旧 7 个文章、3 个地点、3 个练习 ID 保持可解析。题目依据指向同篇的现存段落。媒体许可页面、作者、日期、地点、画面内容及尺寸齐备后再计入发布量。内容包保存校验值，老安装包不得把新版内置资料降级。

## 5. 响应式与验收

- 对照 390×844、430×932、1024×768、1194×834。短屏 320×568 与 1.5 倍字号额外核对目录、图例、词语面板、表单、键盘及底部按钮。大字号阅读顺序优先于卡片并排。
- 沿用全局 token。浅背景 `#F4F7FB`、白色内容、主字 `#12243A`、深海蓝 `#12395B`、橙 `#FF9A3D` 配深色字。圆角 16/12dp，内容边距 20–24dp，主操作高 ≥52dp，触控 ≥48dp。沙色与水绿通过照片、地理资产和图例表达。平板地图保留自然比例。
- 同时验证触控、键盘、读屏和减少动态效果。图例有线型、文字和颜色。区分地图数据、标注和图解。图片缺失可读图注，地图加载失败给同一批真实对象的列表。草稿恢复依赖保存成功的本机状态。地图返回原焦点、文章回原段、题目回反馈。
- 从既有 7 篇与已安装旧包升级，检查稳定链接、旧笔记/收藏、实际进度、试题历史。使用已下载内容测试断网进入概览、地图、图集、题目和笔记。新地图数据与资源纳入内置/内容包策略后再验收原生离线。
- 交付顺序建议为数据与概览/目录 → 水系与地点闭环 → 读图、内容和活动 → 布局、离线、迁移与 Android 真机。每阶段有可运行入口和内容校验。
