# 法国 · 从塞纳河走向山海

2026-11-09 · 详细设计1.0 · 待确认、待实现

本轮直接采用生图效果图作为视觉设计，不使用Stitch。主题从巴黎河岸延伸到潮汐海湾、阿尔卑斯冰川和留尼汪火山，兼顾城市生活、语言、饮食、艺术与历史。

- [效果图画廊](index.html)：7组效果图，覆盖14个代表页面；点击查看原尺寸。
- [详细设计](DESIGN.md)：功能范围、三条路线、地图、页面、交互和验收。
- [内容与素材计划](CONTENT_PLAN.md)：十栏目30篇、24题、6观察、12地点、36媒体位及来源核验队列。
- [视觉交接](VISUAL_HANDOFF.md)：视觉参数、各页重点、事实修正与逐页还原规则。
- [生图记录](imagegen-manifest.json)：原始提示词、内置工具、文件路径和画板对应关系。

法国欧洲部分必须包含科西嘉；海外首发五个省级地区的区域视图，并明确这不是全部海外地区。实际边界和正式纪实照片在实现阶段核验。效果图中的地图与照片不作为教学证据。

本轮仅新增设计文档和图片，没有修改运行内容、Flutter页面或国家发布状态。用户确认后，以确认效果图为视觉基准开发，不额外制作另一套Stitch设计。
