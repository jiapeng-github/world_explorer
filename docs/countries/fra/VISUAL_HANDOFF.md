# 法国效果图 · 开发视觉交接

本轮使用内置image_gen，不使用Stitch。7组效果图覆盖FR01–FR14；它们是视觉概念原稿，尚待用户确认，不是已上线页面截图。图片中的地理与纪实画面仅为设计占位，正式实现必须使用核验GIS与有许可素材。

## 固定视觉参数

- 应用logo沿用用户此前确认的现有资源；效果图里的书本等符号只表示应用标识位置，不另起一套logo。
- 背景#F4F7FB；卡片#FFFFFF；主色#12395B；文字#12243A；次级文字#59718A；橙色#FF9A3D；线框#DCE5EE。
- 手机基准390×844dp；左右边距20dp，正文区宽350dp，8dp间距网格；卡片圆角16dp，图片12–16dp，触控≥48dp，主按钮高56dp。
- 中文Noto Sans SC；页面标题28/36dp，阅读题目30/40dp，章节标题22/30dp，正文18/30dp，说明14/21dp。字号上调时自然换行，不固定卡片文字区高度。
- 国家首图约260–280dp，标题靠左下留出照片主体；卡片图片16:10，正文图优先完整可辨、建议16:9；重点对象不得被标题/来源按钮遮挡。
- 主题照为巴黎河岸；不叠满国旗、不使用卡通吉祥物，不把所有图片都染成蓝橙两色。橙色用于主要行动与当前选择，不涂满每个卡片。
- 阅读页固定底栏：目录/听讲解/收藏/笔记。国家页保留单一底部主行动。地图和国家百科入口沿用发现/地图/百科/我的全局导航，不混用两种底栏。

## 各组原稿的视觉重点

01概览与目录：照片优先，正文和按钮有明确层级，三路线图片大小一致，十栏目不能少项；首屏下方内容允许正常滚动，不为硬塞一屏缩小字体。

02地图：欧洲部分含科西嘉；海外用世界定位与地区卡，不把岛屿挪到法国海岸。画稿地图边界仅示意，正式以GIS为准。海外覆盖提示必须保持可见、可读。FR04同时呈现范围导航与选点，是地图导航状态，不要求把所有层级永久挤在同一个首屏。

03潮汐：固定同一个岩岛与视角，用蓝色水位区分低潮/高潮；生成的两张实景不能作为真实潮位比较证据。正式对照必须用可比实拍，或者明确原创示意。热点跟随原图坐标，并提供列表文字。

04艺术与历史：档案和画作不要当壁纸铺满；年代卡不按实际年距。原创练习画不能标成某位画家的馆藏真作；若换成馆藏作品，改写真实作品名、作者、年代与许可。

05日常与自然：图片要有具体地点。冰川保留石屑和谷地，不美化为无瑕雪山。流动图与退缩资料分开，不能给生成图标假日期制造证据。

06探索与发现：计数为真实0，不把设计示例进度写入用户数据库。最终稿任务已统一为“在熔岩上找纹理”，与fra-p05对应；不新增没有正文支撑的考题。

07路线与记录：三站是阅读顺序。笔记输入框空白，示例不预填；空态保存为禁用灰色。填写一项后主按钮橙色，保存中显示进度，失败原地保留文字。

## 视觉验收方式

用户确认原稿后，将确认版本记录到README与manifest，后续原图迭代保存v2而不覆盖。每个代表页面输出390×844实际运行截图，使用同一文字尺度并排比对：主图高度与裁切→标题与正文层级→内容块顺序→间距→按钮与底栏→图标细节。对图中无法精确实现或事实不准的部分先记录差异，事实与可访问性优先，不能悄悄把设计降为现有组件的默认外观。

区分三类状态：效果图只冻结可见默认态；交互态按DESIGN实现；正式纪实媒体按CONTENT_PLAN核验。视觉通过、功能通过和内容审核分别记录。生图文字若有错误，以开发文档的准确文案修正，不复制错误；不得以此为理由重排整个页面。

待确认交付没有修改lib、运行catalog、版本号或发布状态。下一步实现时才下载正式素材、制作GIS、录入全文和编写测试。
