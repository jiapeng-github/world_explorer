主题为「沿着泰晤士河出发」。先看一条河怎样穿过伦敦，再从地图走向山谷、海岸和不同社群。每篇围绕一个孩子能提出的问题，学习路径为看照片、读解释、找地图、寻找证据、留下发现。保持中国、埃及、美国模块已确认的现代地理图鉴风格。

## 1. 范围与发布约定

沿用目录 ID `gbr` 和代码 `GB`，不新建 `uk` 或 `england` 国家记录。本轮是设计交付，现有运行目录仍为 basic。内容与素材审核、功能验收通过后再发布。百科隐藏未完成国家；世界地图保留英国预览，并显示禁用「即将上线」。不增加「离线百科」标签。

首版目标为十栏目、30 篇独立正文、12 处地点、3 条阅读路线、24 道闭合题、6 项开放观察、36 个媒体位、6 种图解、14 个代表页面与状态。每篇 450–650 汉字、4–6 段，可先读约 80 字概要；每次探索约 3–5 分钟，不强制计时或连续打卡。正文、照片、地图数据可随内容包离线使用。

英国由英格兰、苏格兰、威尔士、北爱尔兰四个组成部分构成。给孩子使用「四个组成部分」，进阶词条说明英文 constituent countries；不把它们类比为四个州。大不列颠岛是地理概念；北爱尔兰位于爱尔兰岛东北部，爱尔兰是另一个国家。王室属地和海外领地不并入这四部分。来源见 CONTENT_PLAN 的 S01。

## 4. 地图详细设计

### 地理范围和层级

默认整幅图涵盖英国及周围海域，同时保留完整爱尔兰岛和法国北岸的上下文。四组成部分可点选，高亮使用描边与文字双重识别；爱尔兰独立国家底色保持中性。图例区分国家边界、英国组成部分边界与水系。英国行政边界不沿整座爱尔兰岛外轮廓绘制。

英国全图包含设得兰、奥克尼和外赫布里底群岛。首版用同一比例全图和「全英 / 英格兰 / 苏格兰 / 威尔士 / 北爱尔兰」相机范围预设，不裁掉远岛。小屏用列表帮助找远处地点，不用误导尺度的装饰插图。国家概念与岛屿概念有「认识这些名字」切换，行政区域着色与岛屿轮廓分开显示。

图层为地形/水系/地点。首发水系为泰晤士河、塞文河、尼斯湖。河道可点到线，湖泊可点到面，区域可点到多边形。海域文字包括大西洋、北海、爱尔兰海、英吉利海峡；海域标签不冒充可答题对象。水系对象使用完整语义，泰晤士河口以数据范围注明潮汐河段，不靠直线连接地标拼河流。

### 数据和实现

统一输入 WGS84，建议英国区域采用自定义 Lambert Conformal Conic（中央经线 -3°，标准纬线49°/61°，纬度原点55°），点、线、面、栅格共享同一投影。实际参数需在数据制作时固定并校验全国覆盖。避免直接用仅覆盖大不列颠的数据集代替全英国，尤其核对北爱尔兰。

边界优先选 ONS/Open Geography 四组成部分数据，水系与邻国轮廓考虑 Natural Earth 1:10m；若河道或小岛细节缺失，补齐有明确许可的机构数据。每份数据在实现阶段登记下载页、版本、许可、原始文件摘要、简化误差和构建脚本。本轮不声称已取得GIS授权。多岛与洞环保持拓扑，河流命中宽度随屏幕设置，最低可交互宽度通过容差保证。

稳定区域 ID 为 gbr-part-england / scotland / wales / northern-ireland。水系为 gbr-feature-thames / severn / loch-ness。地点、区域、水系均能从同一搜索列表进入。搜索支持英国/United Kingdom/UK、英格兰/England、大不列颠/Great Britain（地理解释卡）、北爱尔兰/Northern Ireland、Caerdydd/Cardiff、Eryri/Snowdonia。搜「爱尔兰」同时列出爱尔兰国家、爱尔兰岛与北爱尔兰，类型和说明必须清晰；当前国家列表不把爱尔兰作为英国组成部分。

手机面板提供25%/50%/85%三档及按钮；平板右侧320–360dp详情栏。缩放、选区、切层不算地点浏览，打开地点页才记「看过」。从阅读返回保持原文位置；从地点返回保留镜头、层、选点、面板。全图重置当前范围，返回上一个区域可恢复其镜头。路径参数使用 country/layer/part/place/feature；对象优先于冲突的 part，未知对象回到可用列表并提示。地图不可用时仍可阅读列表、搜索、打开地点与文字答题。

## 5. 阅读、任务与记录

GB05 以科学证据解释玄武岩冷却与收缩产生柱状节理，配独立「传说」卡讲巨人的故事。柱顶边数不一，不能把每根都画为完美六边形。图解标「示意」，不把生成照片用于正式证据题。

GB08 用经核验的实拍和对应文字解释威尔士语地名；Caerdydd/Cardiff 指同一座城市。材料可扩展到苏格兰盖尔语、Scots、爱尔兰语和各地社群语言，不暗示全国只讲两种语言，不据口音或衣服猜族群。

历史页精选约公元前2500年巨石阵石圈、1825年斯托克顿—达灵顿铁路开通、1928年男女投票资格趋于同等条件三个节点。日期带出处，节点不按实际年距。巨石阵的用途保留不确定性；铁路不写成「人类第一条铁路」；1928不写成「历史上所有人第一次能投票」。延伸卡解释工业增长也伴随童工、污染、殖民与不平等，使用适龄语言及具体来源，避免单向赞歌。英国组成历史的1707/1801/1922/1927不得混为一个成立年份，首版不以单一「建国年份」当知识点。

所有闭合题均有未选、已选、正确、待重试、证据回读状态。确认前可改答案；错误无倒计时、无扣分惩罚。照片或地图操作均有等价文字选项。读图题与任务页共用同一 exerciseId；开放观察不设标准答案。

笔记三个字段均可选，至少一项含非空白文字才可保存；保存中禁用重复提交；失败保留输入。草稿按国家、来源实体和任务保存；返回后恢复，成功写入后清理草稿；编辑/删除/撤销沿用现有记录流程。计数来自实际本机数据，不预置样例记录。无可用朗读语音时显示说明并保留全文。

## 6. Flutter 开发交接与验收

复用 CountryExperienceScreen、CountryContentsScreen、EditorialSectionScreen、CountryJourneyScreen、ReaderScreen、CountryTimelineScreen、CountryObservationScreen、CountryDiscoveriesScreen。国家差异放入 gbr editorial 配置，避免对英国复制整套中国/美国屏幕。地图新增英国 profile 与数据文件，沿用世界/国家地图分离。现有字段不支持多语别名、来源审核状态或投影时再做最小迁移，兼容已有内容包。

源内容拟存 tool/content/editorial/gbr.json，媒体清单拟存 gbr_assets.json。目录由 build_catalog.py 生成，首版 revision 1。文章 ID 采用 CONTENT_PLAN，块为 <articleId>-b1…，题目绑定 evidenceBlockIds；地图题绑定 featureId/placeId/partId，照片题同时绑定 mediaId 与归一化坐标。正式图片的焦点和裁切规则随媒体保存。生图稿不得直接复制成整张可点击页面。

验收顺序：内容ID和引用校验 → 媒体与许可 → 地图几何与命中 → 交互与回退 → 多尺寸 → 离线内容包 → 原有国家回归。首发前确认：

- 十栏各3篇独立全文，24道闭合题+6项开放观察全部可达，12地点有图文，三路线引用准确。
- 全英四部分范围、北爱尔兰邻界和远岛完整；搜索同名概念分开；伦敦、巨人堤、卡迪夫、格伦科定位正确。
- 未选确认禁用、错误重试、证据回读、文字作答和返回状态正确；照片裁切后热点仍落在对象上。
- 观察空白不可存、草稿恢复、保存失败可重试、连续点击不重复计数、笔记删除后计数更新。
- 390×844、430×932、1024×768、1194×834；另核320×568及1.5倍字体。点击范围≥48dp，正文18dp/约1.65行高，主按钮≥52dp。
- 字号变大时正文与卡片自然增高；小屏地图优先保留清晰的列表；键盘弹起后仍能滚动到保存。
- 正式照片有真实来源和许可；图注有地点、年代或拍摄时间未知说明；事实来源核验日期单独记录。
- 发布后断网可阅读、地图可显示、搜索可用；中国/埃及/美国回归通过；未发布国家仍按原规则隐藏和禁用。

## 7. 视觉基线

背景#F4F7FB、卡面#FFFFFF、深海蓝#12395B、橙色#FF9A3D、正文#12243A。沿用现有字型和图标。照片主色以河水蓝、山谷绿、玄武岩灰为主，橙色只强调选中与下一步。标题24–32dp，正文18dp，辅助14dp；卡片圆角16dp，手机边距16–24dp。正文和地图图注不叠在低对比照片上。详见 VISUAL_HANDOFF.md 与原稿画廊。
