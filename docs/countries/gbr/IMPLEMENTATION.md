# 英国模块 · Flutter 实现记录

应用 0.7.0+7 · 内容 2026.11.9.1 · 2026-11-09

从「百科 → 英国」进入「沿着泰晤士河出发」。英国已作为完整内容显示，世界地图中的英国可探索；其它未研发国家继续显示不可点击的「即将上线」。未添加「离线百科」标签。

## 已实现

- 十栏目各三篇，共30篇原创正文，每篇五段、450–650汉字；每篇连接一项核心活动及来源。
- 三条路线：沿着河流进城、去海岸找线索、顺着时间找证据；12处地点带实景、正文、地图锚点与可点按热点。
- 12道选择题、6道定位题、6道读图题；答案关联本篇证据段。6项开放观察支持本机笔记，发现页使用真实阅读、地点和笔记记录。
- 原创图解包括国家与岛屿、河流与桥、地铁换乘、石柱冷却、共同节拍、海鹦生境、双语名称和等高线。线路图为虚构教学例图。
- 36项有署名与许可的照片、历史影像和示意档案随包提供；没有把生图稿作为纪实素材。

## 地图

以 Natural Earth 1:10m Map Units 的四组成部分真实几何为底图，LCC投影统一全国与分区；包含苏格兰北部群岛。支持拖动缩放、区域镜头保留、搜索、地点列表、图层、比例尺和手机抽屉/平板侧栏。泰晤士河、塞文河与尼斯湖来自同系列水文数据。地形采用NASA Blue Marble重采样；构建脚本、源文件摘要和投影参数保存在仓库与地图JSON中。

「认识岛屿」切换大不列颠岛与爱尔兰岛范围；爱尔兰独立国家、北爱尔兰与爱尔兰岛在搜索中分别列出。马恩岛与海峡群岛不计入英国四组成部分。地图加载失败时仍可从地点列表进入正文。

这是学习用简化地图，边界不是测绘级导航数据；岛屿由主要陆地的多个多边形组合，局部接缝仍可能可见。地点使用公开景观或建筑的代表点，不把区域锚点冒充每张照片的摄影位置，不标海鹦巢穴。

## 原稿与实拍调整

保留原稿的深海蓝/橙色、白底卡片、大图与阅读层级，复用此前已实现的阅读工具栏、笔记和路线组件。正式画面依真实授权照片调整裁切与热点：

- 双语照片为「卡迪夫湾」车站场景，Caerdydd/Cardiff 用原创文字卡清晰对照；Bae/Bay 另作解释。
- 海鹦主图使用衔鱼实拍；正文题为「海鹦在哪儿获得鱼类食物？」海里/草地上。
- 爱丁堡草市广场图为历史影像，明确不能当今日街景。凯利舞图摄于英格兰活动，不标成苏格兰现场。
- M23机车图摄于2009年达灵顿旧陈列地；地图标希尔登博物馆。M24是后来出版的1825年铁路题材插图。M34记录1911年游行，不作为1928年法案现场照片。
- M35展示塔内钟面，不声称展示Big Ben大钟本体。茶树图摄于印度，不标成英国茶园。

所有图片许可、作品页、下载地址、实际尺寸、SHA256和日期在 [媒体清单](../../../tool/content/editorial/gbr_assets.json)；原始作品元数据在 [素材来源记录](../../../tool/content/sources/gbr_media_metadata.json)。内容的机构来源逐篇列于 [内容数据](../../../tool/content/editorial/gbr.json)，正文源稿与生成器可重建JSON。
