# 英国 · 视觉交接

> 实现状态：英国已在 0.7.0+7 中实现。本文保留设计阶段要求；实际内容、素材与验证结果见 [IMPLEMENTATION.md](IMPLEMENTATION.md)。

本轮7张生图原稿覆盖14个代表页面和状态。它们用于确认构图、色彩与信息层级。最终Flutter使用真实文本、组件、GIS和取得许可的照片。Stitch为可编辑结构参考；最终文案与行为按DESIGN.md及CONTENT_PLAN.md。

## 必须保留

- 概览首图占首屏约三分之一，英国标题、短事实、路线卡与主要行动清晰分层。
- 目录双列图片卡、真实风景的蓝绿灰配色、深海蓝文字与橙色行动强调。
- 平板地图的导航/地图/详情三栏；手机地图与可展开底部面板。
- 阅读页的「问题—照片—解释图—小题」顺序，地点页的编号观察线索。
- 历史的资料卡、两种语言的对照、路线的有序卡片和三栏观察表单。
- 无记录时的零计数与温和引导，空表单的灰色禁用保存按钮。

橙色按钮文字统一深海蓝，避免原稿部分白字对比不足；白字用于深海蓝按钮。导航、卡片与焦点沿用现有App组件，不能因生成稿自带阴影或渐变就重做全局风格。正文18dp，行高约1.65，手机左右16–24dp。小屏以滚动承载全文，不能为了把长文塞进一屏而缩小字。

所有生成风景、地图、历史档案占位图仅用于设计评审。正式图注要写作者/来源/年代；没有拍摄日期明确写未知，不编造。按钮行为、反馈、无网络、朗读不可用、文字放大等状态以详细设计为实现依据。
