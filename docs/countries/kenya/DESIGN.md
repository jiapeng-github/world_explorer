# 肯尼亚 · 从赤道高山走向印度洋

设计 1.0 · 2026-11-12。以生图效果图作为视觉基线，不使用 Stitch。设计基线已进入实现；实际交付与验证记录见 [IMPLEMENTATION.md](IMPLEMENTATION.md)。

## 学习目标与范围
面向 8 岁孩子，帮助理解纬度与海拔、自然空间与人类生活、观察与证据。由现有 8 篇扩充至十栏目 30 篇；12 处地点、24 道闭合题、6 项开放观察、3 条阅读路线、8 类原创图解、36 个媒体位。保留国家 ID `kenya` 和现有八篇稳定 ID；更新正文版本时保留收藏与笔记，复用阅读进度需判断正文是否已实质改变。

三条路线均为三站阅读顺序，不是交通路线：
- `mountain-water` 高山与水：赤道高山 → 裂谷与湖泊 → 水流的去向。
- `city-coast` 城市与海岸：内罗毕城市生活 → 蒙巴萨港口 → 拉穆木门。
- `living-space` 生命的空间：大象栖息地 → 卡卡梅加森林 → 海岸红树林。

肯尼亚以现代城市、高山、湖泊、森林和海岸共同呈现。具体社区的文化说明归属，避免将某一服饰、舞蹈、民族或动物代表全体国民。历史介绍英国殖民统治、土地与权力的不平等、反抗和争取独立；不将殖民时期只描述成铁路和旅游发展，不展示血腥影像。

## 地图开发规格
使用真实 WGS84 点线面，建议当地 Lambert Azimuthal Equal Area：中心纬度0°、经度38°，实际参数、单位、轴方向写入manifest，并用 PROJ 独立验证。支持德国模块同级交互：图层、搜索、点线面命中、相机与选择恢复、深链、缺失资源文字列表。

全国包括真实海岸与近岸岛屿；相邻国家淡化。赤道是纬线，使用不同于国界的线型。维多利亚湖与图尔卡纳湖保留跨境范围；湖面不能整体涂成肯尼亚。肯尼亚山与坦桑尼亚境内乞力马扎罗山明确区分，安博塞利照片远山若为乞力马扎罗须标明。伊莱米三角地带按数据来源展示争议或未定边界，并附地图范围说明，不擅自将争议画成无争议国界。

首发地形、水系、地点三层。47郡行政层仅在有完整合法数据与核验后添加。裂谷为有来源的概略自然区域，不将一条断裂线当成整个区域；没有合适面数据时改用已核验湖泊定位题，不能伪造面。动物栖息空间图为关系示意，不做精确迁徙线、固定角马日历或旅游导航。

搜索支持 Kenya／肯尼亚、Nairobi／内罗毕、Mount Kenya／肯尼亚山、Lamu／拉穆、Mombasa／蒙巴萨；不承诺未开发地点详情。真实地点和图层实体分开。点选不计入已看地点，进入详情才计数。比例尺随相机变化，文字等价选项供读屏和低精度触控使用。

## 视觉规格
延续批准的现代地理图鉴：白底、#F4F7FB、深海蓝#12395B、橙色#FF9A3D。照片中引入高山绿、湖水蓝与珊瑚石暖色，不更换全App品牌色。沿用现有App logo。

390×844基准、20dp边距、8dp间隔；标题28/36，正文18/30，图注14/21；照片12–16dp圆角、卡片16dp；主行动高56dp，触控目标至少48dp。主图260–280dp；手机两列目录，大字改一列。平板地图左侧详情320–360dp、右侧地图，窄屏与大字恢复上下布局。动效尊重系统减少动态设置，节奏练习有文字替代且退出取消计时。

## 实现顺序与验收
1. 先冻结30篇内容与证据、稳定ID、素材许可；不得仅以标题占位标记完成。
2. 制作真实GIS、照片、八图解，校验海岸、赤道、跨境湖、争议边界和地名。
3. 逐页对照七组效果图实现14状态，接入收藏、记录与任务。
4. 校验全部文章、24道闭合题和6项开放记录引用；每媒体记录来源、许可、日期、SHA256；旧8篇收藏笔记迁移回归。
5. 截图验证390×844、430×932、1194×834以及320×568/1.5倍字体；测试地图返回、切层、问题证据、草稿保存、真实空状态和其余国家回归。
6. Android/Web编译，安装包内资源核验；真机断网阅读与语音能力单独验证。功能测试不替代逐页视觉验收。
