# 挪威 · 从峡湾海岸走向北极之光

设计1.0 · 2026-11-12。以生图效果图为视觉基线，沿用已确认的现代地理图鉴。此轮交付详细设计与效果图，尚未修改App业务代码，不把概念图片当作已实现页面。

## 学习目标与内容范围

让8岁孩子从“看见一张漂亮风景”走向理解地形、生活与历史之间的关系：峡湾是海湾而非长河；极昼与极光是不同现象；挪威既有北方自然，也有今天的城市、多语生活和不同社区。

从现有八篇扩展为十栏目30篇、12处地点、24道闭合题、6项开放观察、3条三站阅读路线、8类图解和36项素材。保留国家ID `norway`，已发布文章和地点稳定ID见CONTENT_PLAN。

三条路线为阅读顺序，不是旅行交通路线：

|ID|路线|三站文章|
|---|---|---|
|fjord-wood|峡湾与木城|norway-geography → norway-history → norway-urnes|
|city-daily|城市里的日常|norway-daily → norway-food → norway-people|
|northern-light|北方的光与生命|norway-nature → norway-aurora → norway-sea-ice|

每篇五段、450–650汉字，约4分钟，提供术语解释、图片来源、一个核心任务。正文的国家知识应占主体，读图与来源方法服务于具体主题，避免每段反复堆叠“照片不能证明”的提醒。

## 首页与视觉规格

沿用白底、#F4F7FB、深海蓝#12395B、橙色#FF9A3D与现有App图标。照片提供峡湾蓝、山坡绿、木屋红和克制的夜空绿色，不把整个模块改成黑色极光主题。

390×844手机基准；20dp页边距；8dp间隔体系；标题28/36、正文18/30、图注14/21；卡片16dp圆角；主按钮56dp高；触控区域不小于48dp。首页主图约270dp，事实为奥斯陆／首都、欧洲北部／位置、山地与峡湾／地形。语言知识放在正文完整解释，不挤成“唯一官方语言”标签。

三路线卡保持等宽；两问题链接为“峡湾是河流，还是海湾？”与“午夜为什么还能看见太阳？”。无进度时按钮“从峡湾开始”，有未读完文章时“继续阅读：标题”。目录两列；320dp或1.5倍字体切一列。任务头图为三图拼贴，发现页推荐为双列照片卡，大字回落单列。

阅读页只有“目录／听讲解／收藏／笔记”工具栏。地点页只有“在地图上找它／记下我的发现”主操作。品牌和导航采用现有App规范；生图出现的桌面导航、重复品牌栏、不同logo或个人头像不纳入实现。

## 地图范围与实现要求

### 分图与投影

- `mainland`：挪威本土、沿岸岛屿与邻国参照；建议WGS84椭球LAEA中心65°N、15°E。
- `svalbard`：斯瓦尔巴群岛完整岛屿范围，保留熊岛等离散部分；建议中心78°N、20°E。
- `jan-mayen`：扬马延岛完整形状与海洋背景；建议中心71°N、8°W。
- 每分图独立相机、比例尺、投影参数与北向指示；明确“分图比例尺不同”。不把岛屿拖近本土伪装真实距离。定位题跨分图展示时保留当前选择，未确认不自动答题。
- 国家地图范围为挪威本土、斯瓦尔巴与扬马延。布韦岛等南极属地不混入本土图；范围说明明确本版不提供其专题。斯瓦尔巴、扬马延在卡片上用地域名，不混用“属地”标签和南极依属领地概念。
- 地图数据世界层若把Svalbard/Jan Mayen编码为不同实体，须建立明确实体到norway的映射，去重并测试；不能仅筛ISO NOR就声称包含全部范围。

### 图层、交互与数据

首发地形、海岸、地点三层。地形底图只提供视觉背景，不从颜色直接读取海拔；海岸层显示真实海岸线与有出处的海湾范围；地点层显示12个代表点。地名需支持Norway／Norge／Noreg、Oslo、Bergen／Bryggen、Geirangerfjord、Tromsø／Tromso、Svalbard／Longyearbyen等别名。

GIS优先使用Kartverket、挪威极地研究所许可合适的数据，Natural Earth可用于总览和邻国。细峡湾若超出源数据分辨率，应另找合法精细海岸数据；没有可靠面时用明确标注的代表点和文字信息，不拿细河线冒充峡湾水面。海湾水体与开放海洋连通，不能错误涂成内陆湖。所有几何、许可、坐标转换、投影轴方向和输入哈希保存到manifest。

北极圈按采用历元的地轴倾角推导，教育概述可写“约北纬66.56°”，标为假想纬线、非国家边界；开发记录采用历元和公式。几何来自坐标，不能追描生成地图。地图比例尺随缩放更新；不同图层用颜色和线型双重区分。

点、线、面命中分别实现。线命中有触摸容差；多个邻近点提供聚合列表；无精细数据时显示真实文字列表。保留缩放与选中状态，返回后恢复。手机抽屉25/50/85%，平板左侧320–360dp详情、右地图。地图选中不记“看过地点”，进入详情才记录。深链无效地区／地点应回退到合法范围并说明，不能白屏。

## 互动设计与真实状态

- 峡湾图：冰川侵蚀、冰退后的山谷、海水进入，标为原创过程关系，不制作伪装成实测的“古今照片”。三阶段不表示每处峡湾完全相同的时间过程。
- 极昼图：纬度／季节与地轴倾斜共同解释；夏冬切换不改变自转轴在空间的基本方向。奥斯陆与特罗姆瑟做纬度对照；地平线遮挡和大气折射另说明，不写没有来源的精确起止日期。
- 极光图：太阳活动、磁场和大气关系分层展示。摄影色彩可能受曝光处理影响；不把图片当作当晚观测保证。
- 闭合题：未选禁用；确认后解释、证据回读；答错可重试不扣分；选择状态与结果持久化。图解交互不自动选择答案。
- 观察：三空字段至少一项非空可保存；防重复提交；失败保留输入并重试；离开自动保存草稿，返回恢复；成功后出现在真实发现列表，可编辑。没有历史记录时不显示“继续上次”。
- 所有照片有查看原图与来源入口，证据重点在裁切后仍可见；教学卡使用完整画面。热点按实际照片重新标注，不沿用生图坐标。
- 听讲解复用现有中文TTS；不把系统合成声音称作萨米原生录音。文化录音如后续新增，需独立许可与说话者语种核验。

## 内容边界与重点核验

峡湾与冰川、北极圈与国界、极昼与极光、海冰与陆地冰川分别讲清。挪威南北差异大，不写“全国全年冰雪”。北极熊内容放在斯瓦尔巴／北极海冰语境；不把它画进本土城市，也不加入企鹅。

Bokmål与Nynorsk首先是书面规范；萨米存在多种语言和不同当代生活。萨米文化可包含工艺和驯鹿，但不能只呈现传统服饰或牧业。以官方／社区资料核对同化历史、语言损失与复兴，尊重不同讲述者。不创造未经来源支持的服饰寓意或祈祷歌词。

历史区分1814宪法、同年与瑞典的联合和1905联合解体；1940—1945含纳粹占领、迫害、抵抗与解放，采用适龄非血腥表达，不只讲童话、维京和风景。布吕根火灾与修复意味着“旧样式”不等于“每根木料都很古老”。历史照片无法取得时使用明确标注原创的事实摘记，不能生成伪档案。

## 开发与验收顺序

1. 冻结30篇正文、证据、24题与6观察；确认旧ID和重写段落迁移。
2. 取得真实照片、地图与许可，完成36项素材台账及8图解；未完成资料不标记开发完成。
3. 对照七组效果图实现十四状态与三地图分图；重建GIS、比例尺与热点。
4. 测试30文章、12地点、24题、6观察、3路线、草稿和真实计数；确认旧8篇收藏笔记保留，旧题归档，旧包不能覆盖新版内置内容。
5. 在390×844、430×932、1194×834、320×568／1.5倍字体截图；另核地图三分图、无搜索结果、地图失败列表、保存失败与减少动画状态。逐页并排视觉检查。
6. Flutter静态检查与全项目回归；Android/Web构建后核对正文、媒体哈希、地图与打包版本；真机断网阅读、TTS可用性另记实测结果。
