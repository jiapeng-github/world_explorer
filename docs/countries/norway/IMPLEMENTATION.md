# 挪威专题实现说明

2026-11-12。以七组已确认效果图和DESIGN.md为基线，已接入现有Flutter应用。入口为百科中的挪威卡片或地图中的挪威；直接路由`/countries/norway`。

## 内容与交互

- 10栏目、30篇五段原创正文，每篇450–650汉字；24道闭合任务（12选择、6定位、6证据）及6个开放观察；12地点、3条三站阅读路线、8种互动关系图。
- 原有8篇文章和2个地点的ID及主题保留；正文revision=2、新段落ID；旧三题归档。旧进度可存档并从新版开始，收藏、笔记保留；旧下载包不能覆盖新版内置内容。
- 首页、照片目录、历史线索、日常生活、任务筛选、真实发现计数和阅读路线已实现；没有记录时不预填答案或虚构完成状态。
- 地点页有双图切换、原图与来源、地图入口和三栏观察；盖朗厄尔与布吕根绑定正式照片热点。观察复用现有草稿、保存失败重试和笔记存储。
- 内嵌题与独立题共享作答ID，返回时恢复挪威已提交答案。分图切换只改变地图视图，不提交定位题；选择后仍需确认。

## 地图

三个独立WGS84椭球LAEA视图：本土65°N/15°E、斯瓦尔巴78°N/20°E、扬马延71°N/8°W。Natural Earth Map Units中的NOW/NSV/NJM映射到norway，排除BVT；斯瓦尔巴保留熊岛。世界总览110m会省略小岛，已有50m放大层包含扬马延与熊岛，专题10m数据进一步细化。

支持地形／海岸／地点图层、城市与英文别名搜索、点聚合、线与面命中、缩放、北向、动态近似比例尺、地域相机记忆。手机地点面板25/50/85%，平板左详情右地图。地图选中不记为看过地点，进入地点详情才计数。

北极圈按2026-11-12历元与IAU平均倾角公式生成坐标，显示约66.56°N，使用虚线和文字说明。输入数据及哈希、投影参数、PROJ对照点保存在`assets/atlas/norway-regions.json`，构建脚本在`tool/maps/build_norway_regions.py`。

细峡湾没有可靠水面边界时使用明确的代表点，不画虚构河线。本土及斯瓦尔巴使用NASA Blue Marble影像背景；扬马延因全球栅格分辨率不足采用清晰的矢量范围图。尝试取得更细NASA WMS影像时源站超时，未将放大像素块作为地形细节发布。

## 正式媒体与视觉校正

37项媒体：27张保留来源与许可的Commons照片、10张原创教学卡。相对原36位规划额外增加M37公共空间图，确保P03依据明确，不把生成图片当成现场。M22、M24采用设计允许的资料摘记；阿尔塔两项采用岩画记录照片，没有冒充遗产地全景。所有记录包含作者、许可URL、日期说明、尺寸、哈希及处理方式。

概念图中的照片与地图已用正式材料替换；保留白底、深海蓝、橙色与既有App标识。极昼图按地轴方向、受光半球和高纬地点运动投影重画；夏冬切换不自动选择题目答案。历史卡明确标注原创摘记，不制作假档案；木教堂照片对应乌尔内斯。

[实装截图画廊](implemented/index.html)提供十四核心状态、三地域分图及平板地图。截图文件由Flutter测试实际渲染导出。
