## 规划范围

10个栏目、30篇文章、12个地点、24个闭合任务（12选择／6定位／6证据）、6个开放观察、3条阅读路线、36个媒体条目和8幅原创图解。以上为原设计范围；实现已补齐30篇正文，并采用37项正式媒体（额外一张公共空间原创示意）。详见实现说明。

保留现有挪威八篇文章主题与ID及两个地点ID。正式实现时遵循内容版本迁移规则。效果图中的文字、地图和品牌符号以视觉交接文档及项目已有规范校正，不直接把整图用作应用页面。
