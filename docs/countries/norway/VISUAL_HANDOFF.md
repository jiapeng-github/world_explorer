七组生图效果图覆盖十四个核心状态，用于布局与风格确认；不是App实际截图。正式实现以DESIGN.md和CONTENT_PLAN.md的稳定ID、内容事实及交互规则为准。

1. 首页峡湾大图、三事实、三路线、两问题、单一橙色主行动；目录三图拼贴与十照片栏目。
2. 地图三图层与三地域分图，地点照片抽屉；平板使用左详情右地图。
3. 峡湾阅读的三阶段图解与三选一题；地点页双照片、代表位置和观察入口。
4. 历史三组线索；木屋阅读用大图、构件细节和“我看见／需要资料核对”双卡。
5. 日常生活大街景、三张内容卡；极昼阅读的夏季日照照片、科学示意和夏冬对照。
6. 任务三图头图、四筛选、三推荐；发现页0／0／0、真实空态、双列推荐。
7. 三站阅读路线和三栏空观察，禁用保存按钮。

主色沿用现有现代图鉴。图片内品牌标识只是位置示意，开发使用项目已有App logo。统一全局导航为“发现／地图／百科／我的”；仅阅读页用“目录／听讲解／收藏／笔记”。删除生图额外桌面导航，不将顶部品牌栏和返回栏重复堆叠。

## 必须校正

- 地图不是可以直接贴图发布的真实地图；重建全部几何、北极圈、海岸、岛屿、地名、选中位置和动态比例尺。生成图中纬线倾斜、海湾宽度、边界、临近国家与地域面积不能作为依据。
- 本土、斯瓦尔巴、扬马延使用独立比例尺与投影；完整记录熊岛等离岛。不把斯瓦尔巴／扬马延与南极依属领地混称，不把生成轮廓当作真实岛形。
- “盖朗厄尔”“布吕根”“乌尔内斯”“特罗姆瑟”“朗伊尔城”在所有文案中统一，生图别字以文档为准。
- 乌尔内斯木教堂不是博尔贡木教堂；正式用来源明确的实拍。生图多层屋顶或雕饰不能用于建筑识别任务。
- 极昼图中的小圆应表达高纬地点的日运动轨迹，不是行星绕太阳的大轨道；北极圈、地轴、平行太阳光和明暗半球须科学复核。夏季极昼照片中不同时放夜间极光。
- 不能把生成的“Oslo／奥斯陆”中文街牌当作现场摄影；Bokmål／Nynorsk卡使用明确标注原创的术语资料。儿童队伍照片也不能当作真实某年活动。
- 1814、1905和1940—1945卡为原创资料摘记，不制作泛黄“仿原件”来暗示档案真实性。正文清楚写明纳粹占领、迫害、抵抗与解放。
- 所有闭合题按CONTENT_PLAN绑定的唯一任务实现。效果图中的城市比较卡或季节按钮只是探索控件，不自动作为答题结果；极昼页仍需C11三选一和证据回读。
- 热点按正式照片重新冻结坐标；照片裁切不能隐藏题目依赖的木板、接缝或山坡；资料卡完整显示，原图和许可可查看。
- 不预填观察、不显示虚构成就。已有真实记录时才显示续读／续做和计数。路线必须注明“阅读顺序，不是交通路线”。
