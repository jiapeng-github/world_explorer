# 世界大百科 · 美国模块详细设计

设计稿 1.0 · 面向 8 岁儿童 · Flutter 开发交接

**主题是「从大峡谷出发」。** 孩子先在照片中找岩层和谷底的河，再去地图定位亚利桑那州。接下来可以沿着山河走，比较峡谷、间歇泉与大湖，也可以换到城市或历史路线。每一站都能独立打开，读完后可继续观察、答题或记下一条发现。

## 1. 范围与入口

| 项目 | 现状 | 首版验收目标 |
| --- | --- | --- |
| 国家身份 | 目录已有国家 ID `usa`、国家代码 `US`、名称「美国」和世界地图标记。内容覆盖为 `basic` | 沿用稳定 ID。完整内容通过验收后随目录发布 |
| 百科 | 美国尚未列入可阅读国家 | 十栏目，每栏 3 篇独立正文，共 30 篇。发现页、搜索、专题和地图引用同一篇文章 |
| 地图 | 世界地图仅有基础预览 | 相连 48 州、阿拉斯加、夏威夷三个视图。50 州、华盛顿特区、12 个可阅读地点 |
| 阅读与活动 | 美国暂无文章和活动 | 6 种图解、24 道闭合题、6 项开放观察。题目可回到正文证据 |
| 影像 | 美国暂无审核过的模块封面和地点图集 | 36 个媒体位。每个独立素材均记录出处、署名、拍摄时间或档案年代、使用许可和裁切 |
| 探索记录 | 已有跨国家收藏、阅读进度、地点浏览与笔记 | 「我的美国发现」按 `usa` 及关联实体汇总实际本机记录 |

上线后主入口为「百科 → 美国」。在世界地图点美国仍留在世界地图，预览卡可进入国家概览。美国区域地图由「在地图上看看」「打开美国地图」和地点页的定位动作打开。完整内容随 App 内置，网络状态不会改变已经发布的阅读入口。制作中遵循全局显示规则，百科隐藏无正文的国家，世界地图按钮显示禁用的「即将上线」。国家卡沿用现行样式。

## 2. 三条探索路线

| ID | 路线 | 三站顺序 | 学完可以怎么讲 |
| --- | --- | --- | --- |
| `landforms` | 沿着山河走 | 大峡谷 → 黄石 → 五大湖 | 说出河流、地下热水和湖泊各能留下什么地理线索 |
| `cities` | 走进城市 | 纽约地铁 → 华盛顿特区 → 新奥尔良爵士乐 | 从交通、首都和一种地方音乐看见不同城市 |
| `history` | 循着历史找 | 今天的原住民族 → 费城独立厅 → 塞尔玛大桥 | 用族群自己的介绍、建筑和档案区分不同时代的线索 |

每站 3–5 分钟，以文章元数据为准。首次打开国家页显示「从大峡谷开始」，进入 `landforms`。有未完成文章时显示「继续阅读」，附文章名和「换个主题」。路线页用 1、2、3 表示阅读顺序。点任意一站立即阅读。已读来自文章的完成状态。首次「从第一站开始」，已有阅读进度「继续这条路线」，三篇都完成后「记下一个发现」，进入任务目录。线路卡不承担导航功能。

典型路径为「美国概览 → 沿着山河走 → 河流怎样刻出大峡谷？→ 找一找河道 → 在地图上找大峡谷 → 看一张能看见河道的照片 → 写下一个发现」。进入地图或照片时保留阅读位置，返回后继续原段落。选择回答和记录发现均可跳过。

### 概览、目录和阅读

- 概览图片选大峡谷南缘。首页两条固定问题为「河流怎样刻出大峡谷？」和「华盛顿特区在哪里？」。地图入口、完整目录、三处精选地点（大峡谷、黄石、五大湖）与历史入口随页面向下滚动。
- 十栏目沿用既有 `countrySections` 顺序。进入栏目见一张首图、1–2 句导语和 3 篇正文卡。推荐文章和活动链接不计入栏目篇数。窄屏栏目切成单列，字号按系统调整。
- 正文每篇 4–6 段、约 450–650 个汉字，儿童可先读概要。段标题可定位，照片下有来源入口。主术语配 1–3 个辅助词。手机底部固定「目录 / 听讲解 / 收藏 / 笔记」。平板用左目录和右阅读栏，正文约 680dp 宽。语音需由设备提供可用的普通话语音。
- US05 的短读图题在图后出现。可点选「峡谷底部 / 峡谷边缘」并确认。反馈能回读证据段；答对或重试使用同一个练习 ID。阅读页内的小题与任务页中的同题共用记录。
- US08 的节奏练习先给「一句乐句」与「另一句回应」两组可读拍子。可拍手或按两段按钮，点播由用户触发。采用自主编写的节奏示例，文字路径可独立完成。录音样本如有，另核演出和录音权利。
- US10 以三个条件讲清机制。地下水遇热，狭窄通道使水和蒸汽积聚，压力变化后喷出。图解表现概念关系。照片的喷发时刻和公园开放情况需另查当期来源。

### 地图与三个区域

- 默认范围为相连的 48 个州及华盛顿特区，东北侧给五大湖和加拿大留空间，西南方向可见科罗拉多河跨境段和墨西哥背景。阿拉斯加、夏威夷以分开的插图进入。插图分别计算比例，图下注明「插图不按同一比例」。在窄屏可用「相连 48 州 / 阿拉斯加 / 夏威夷」切换，进入阿拉斯加或夏威夷以后可一键返回全美概览。
- 华盛顿州标为「华盛顿州 · 西北部」，首都标为「华盛顿特区 · 东部」。搜「Washington」「华盛顿」同时返回，配类别和位置。明确显示行政类别「州」「联邦特区」。领地不计入 50 州，首版区域图的范围随标题说明。阿拉斯加与夏威夷是两个州。
- 保留「地形 / 水系 / 地点」三图层。地形层用淡边界和简洁州名。水系层显示科罗拉多河、密西西比河及五大湖水面。河道有足够空间时标名称，河流点到线，湖面点到多边形。地点层显示已审核的 12 处地点，近距离重叠时聚合。完整可搜索列表覆盖三个区域。州点选显示州名、地区和该州已录入的地点，跨州公园使用该观察点所在州。
- 平板画布右侧显示当前对象卡，缺省为推荐地点与列表。手机在未选中时折叠，选中后约 50% 高度，可在约 25%、50%、85% 三档切换。滑柄另有文字操作。移动地图、缩放、切层和选择面板均不写入浏览足迹，打开地点页才计为「看过」。按「全图」复位当前区域；切区域后再回来可回到先前镜头。
- 搜索支持中文别名、英文名和 USPS 州缩写。精确词优先，州与同名河流各有类别。美加共用湖泊的知识卡注明跨境范围；「苏必利尔湖」选点是湖岸案例，湖面在图层中单独描画。以五大湖水面或州边界的真实形状解释地理关系。
- 选点从路径参数恢复。支持 `country=usa`、`region=conus|ak|hi`、`layer=terrain|water|places`、`place` 和 `feature`。如来路对象与 `region` 冲突，优先用对象所属区域，参数无效时保留区域和可用的列表。地图同一视图内记忆缩放、中心、图层、选点和面板档位。点选插图进入区域后再显示实际地形。
- 用美国人口普查局的州级 Cartographic Boundary 数据制作精简版多边形。州编号冻结为两位 FIPS，例 `usa-state-04`、`usa-state-53`，联邦特区为 `usa-district-11`。同一行政实体可有多个岛屿与内环。全国水系优先使用能连续覆盖美加、美墨的 Natural Earth 1:10m 和经核验的跨境湖面，局部放大补 USGS 归档水道。每份数据固定版本、出处和处理脚本。标注位置与点击几何使用同一投影与资产。
- 地理数据原始经纬度记为 WGS84。制作脚本分别输出相连区域的 CONUS Albers、阿拉斯加 Albers、夏威夷主岛群的局部区域投影。阿留申群岛预处理跨日界线，不把东经 179° 和西经 179° 画成横跨全球的一条线。夏威夷默认看主要岛屿，州概览应涵盖数据所载岛链。切换后重算比例尺。箭头按视图中心的北向显示，地图来源从面板可查。
- 照片点位与地图经纬度分别保存。每张可交互照片取已核验的坐标，缩放时热点随图移动，裁切后把坐标重新映射。与热点等价的编号列表可用触屏、键盘或读屏点选。照片里的小河若无法确认，换用经核验的另一张照片再设置热点。

州与特区范围、水系与底图资料见[内容核验表](CONTENT_PLAN.md#6-事实来源与素材许可)。

### 历史、活动与发现

历史页先提供「认识原住民族的过去与今天」入口，读到今天的社群及其自称。选「看线索」时看建筑、文件与档案出处，选「看时间」时展开节点年份、解释及原始来源。三条日期线索为 1776 年独立宣言、1865 年第十三修正案、1964 年民权法案。1964 卡链接塞尔玛阅读，正文分别讲 1965 年游行和同年的投票权法。三条节点是精选阅读线索，排序不按实际年距绘制。

| 状态 | 屏幕与反馈 |
| --- | --- |
| 未答 | 地图可点对象，照片可点编号，所有题可用同组文字选项。「确认」禁用，可看提示或返回 |
| 选中 | 加描边和选中标记。更改选择后再确认 |
| 提交 | 给一句证据解释。答错允许再试。回读滚到具体段并高亮，返回保留本次反馈 |
| 开放观察空态 | 先展示来源图及图注。三栏「我看见 / 我猜想 / 我还想知道」都是可选项，保存初始禁用 |
| 正在写 | 任一栏输入非空白字符后启用保存。键盘弹起仍能滚动到三个输入框和保存动作。回退可恢复同一任务草稿 |
| 保存后 | 成功后生成一条观察笔记，更新真实计数。失败保留输入，提示重试。一次提交只生成一条记录 |
| 我的发现空态 | 读过 0 篇、看过 0 处、记下 0 条，可打开观察或推荐地点 |
| 我的发现有记录 | 卡片显示实际时间、原文和来源入口。可按现有笔记流程编辑、删除和撤销 |

照片打开记录页时带上 `placeId` 和可选 `media`，文章开放任务使用 `articleId`。草稿按实体和任务保存，复用现有本机仓库。我的发现按实体 ID 去重。题目得分、答题次数与笔记记录使用各自的已有字段。

篇目使用 `usa-*` ID，段落 ID 用 `<articleId>-b1` 等稳定后缀。练习绑定 `articleId`、`evidenceBlockIds`、选项与 `answerId`，开题包含 `type=open`、观察材料与可选填写项。地点包括坐标、坐标含义、英文别名、媒体、来源与相关篇目。表单保存用本地唯一 ID，回退和重进恢复同一个草稿。范围与编号以[内容清单](CONTENT_PLAN.md)为准。

## 5. 视觉与验收

视觉沿用已批准的现代地理图鉴。使用 `#F4F7FB` 背景、`#FFFFFF` 卡面、`#12395B` 深海蓝和 `#FF9A3D` 橙色，正文墨色 `#12243A`。横向照片用岩层、森林和蓝色湖面区分主题。照片上叠字配独立深色遮罩。手机边距 16–24dp，主按钮高至少 52dp，点击区域至少 48×48dp。正文 18dp、行高约 1.65。颜色之外还有图标、标签、描边或选中状态。全局规范见[视觉设计](../../redesign/DESIGN.md)，逐页检查见[视觉交接](VISUAL_HANDOFF.md)。

- 对照 390×844、430×932、1024×768、1194×834。另用 320×568 和 1.5 倍字号核对导航、地图面板、键盘、按钮、图注与表单。
- 首次从世界地图打开美国预览仍能返回世界地图。由国家页打开区域地图缺省相连 48 州。地区切换、地图放大、相机复位、跨日期变更线、陆地与湖面几何、地标搜索和列表等价路径都可验证。
- 打开含 `region=hi` 的文章来路正确进入夏威夷。搜「华盛顿」看见州与特区两个结果。点科罗拉多河确实命中水道，切地点层能返回同一个大峡谷地点。平板右栏与手机面板给出同一地点信息。
- 在读图题上尝试未选确认、选错重试、证据回读和返回。分别核对地图题与照片题。用文字操作也能完成同一题，答案依据能在正文或材料找到。
- 从吉萨和中国既有地点各走一次回归。用美国观察表单测试空态禁用、键盘后保存、离开再进恢复草稿、重复点按不重复记账、编辑后来源仍可定位。
- 所有 30 篇只计一次，每栏恰好 3 篇。每道闭合题和开放观察都有可查资料。36 个媒体位只有在核对作品页、许可和画面之后才计为就绪。美国发布后验证断网阅读及全球「即将上线」策略。
