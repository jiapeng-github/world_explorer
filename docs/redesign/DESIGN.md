# 世界大百科 · 现代地理图鉴视觉规范

日期：2026-11-01。方向由用户明确选择：浅色、深海蓝与橙色、大幅实景。本文是本轮界面生成和后续 Flutter 组件的共同依据。

## 1. 视觉语言

清晰、明亮、有探索感的现代地理出版物。真实场景承担视觉主角；版面使用大标题、短摘要、简明资料与舒展留白。8 岁孩子应能分辨哪里可以点击、哪里是内容、当前在看哪个国家。

图片使用横向或竖向整幅裁切，保持照片主体完整。轻量地图线、编号和图注表达“图鉴”的组织感。圆角适度，避免把每一小段文字都放入独立卡片。图标采用统一线性样式，并配中文标签。

## 2. 颜色 token

橙色按钮使用深色文字；一般文字不使用橙色细字。照片上的标题放在独立深色遮罩或浅色内容区，不依赖不可控的照片亮度。颜色组合在实现时测量对比度。

## 3. 字体与间距

中文沿用具有现成许可文件的 Noto Sans SC 字体资产，字重以 400/500/700 为主。手机页面标题 28–32，平板主标题 36–44；正文默认 18、行高约 1.65；辅助文字 14–16。正文控制段长，列表标题可换行。

间距采用 4/8/12/16/24/32/48 的基础尺度。手机水平边距 20–24，平板 32–48。卡片圆角 16、按钮 12，主要动作高度至少 52，最小交互区域 48×48。阅读栏在大屏上保持适当宽度，额外空间用于目录或地图。

## 4. 导航与组件

- 四入口：发现、地图、百科、我的；选中项有深海蓝图标/文字与浅色选中背景。
- 主要按钮使用深海蓝底白字；橙色只用于关键强调或少量探索动作，并用深色字。
- 顶部工具仅保留当前任务需要的搜索、返回、收藏等动作。
- 国家卡片：图片、名称、简短特点、内容状态；不把阅读量等运营信息作为装饰。
- 地图详情：照片缩略图、名称、位置、简介和一个主要去向。
- 文章底部工具栏：目录、听讲解、收藏、笔记；选中状态以图标与文字共同表达。
- 来源与许可、下载大小和错误原因在需要决策的位置展示，不挤占孩子的正文阅读。

## 5. 响应式设计

手机参考画板 390×844 或 430×932；平板参考画板 1194×834。导航依据可用宽度切换：小于 600 底部导航；600–1023 紧凑侧导航；1024 及以上允许双栏。

地图平板双栏，手机底部详情面板；文章平板使用目录 + 阅读栏，手机使用底部目录面板；国家与专题列表按可用宽度改变列数，不缩小文字来硬塞相同布局。

## 6. 动效与状态

按钮和选择反馈约 150–200ms，页面过渡约 220–280ms，地图聚焦约 450–650ms；启用系统减少动态效果时减弱镜头运动。无自动轮播、自动跳页或强制播放。

加载占位与最终布局一致；断网仍显示已下载内容；空状态给出一个明确入口。数字和进度必须来自实际数据。

## 7. 生图约定

每个模块单独调用内置 imagegen 生成。十张图共享本规范，通过首张定向稿作为风格参考保持一致。大多数模块展示两个手机画面；地图模块包含平板主视图与手机详情状态。

生成画面以中文为主，优先大字号、短文案、可信的层级。画面中的实景风格图与地图只用于界面概念展示；正式产品替换为有授权照片、审核后的地图数据和可访问文本组件。

禁止把生成的地图轮廓当作生产地理资产，也不能把整张屏幕图片嵌入 Flutter 冒充交互界面。交付保留原始生成图片与提示词；说明图片实际覆盖的页面，不宣称生成稿已经可点击。
