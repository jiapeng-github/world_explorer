## 生成与校对记录

全部图稿使用**内置 image_gen**，未使用 CLI/API 备用通道。先生成发现模块作为视觉基准，其余九个模块以该图为风格参考分别调用生成。完整原始提示词见 [image-prompts.json](image-prompts.json)；两次针对性修改的提示词与最终文件记录见 [manifest.json](manifest.json)。

已逐图检查中文主标题、导航、构图、关键操作和风格一致性。搜索稿修正了生成器额外加入的河流排名和不当历史遗迹描述；离线管理稿将下载示例统一为 18/32 MB、四舍五入显示 56%，并补充包体积。旧修订稿移至 drafts，仅供追溯，不进入最终交付包。

这组图是静态概念设计，核心页面已覆盖；完整 28 个页面及所有加载、空、错误状态还需在 Flutter 实施中按页面规格展开。图中文字以 SCREENS.md 为准。图中实景风格图片、地图轮廓、地理关联线、包大小和数量均为设计示例，不能直接用于百科事实或当作真实运行数据。

正式实现中使用有授权的真实照片和审核后的地图数据；正文、按钮、标签和图例使用可访问的 Flutter 组件。首发内容目标与现有内容数量应在产品中明确区分。

## 本地浏览

直接用浏览器打开 index.html 即可查看最终设计图；也可在本目录运行 `python3 -m http.server 5281 --bind 127.0.0.1`，访问 `http://127.0.0.1:5281/`。

交付包解压后，打开 `world-atlas-redesign-v1/docs/redesign/index.html`。所有图片都在包内，查看设计总览不需要联网。
