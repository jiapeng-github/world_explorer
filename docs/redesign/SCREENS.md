## 3. 逐模块交互

### M01 发现

S01 从上到下：应用名称与搜索入口；一个大幅实景精选国家；一条继续阅读；两到三个专题入口。主视觉只承担一个明确动作“探索这个国家”。精选内容按编辑配置呈现，不显示假实时阅读人数。

S00 可选兴趣标签：自然、动物、城市、历史、生活、文化；支持多选、跳过。没有昵称也能进入。第一次启动展示探索入口，已有记录时优先呈现续读。

状态：首次无记录时以“从一个国家开始”替代续读；精选媒体失败仍保留标题与可点击内容；未安装包可看简介再决定下载。

### M02 地图

手机：顶部搜索与图层按钮，地图占据主要空间，选中后底部三档面板（摘要/详情/全屏），地图控制器不被面板遮挡。平板：左侧地图、右侧详情，筛选和国家选择即时联动。

点击国家轮廓 → 高亮 → 显示名字、国旗、首都和百科入口；点击地标 → 显示照片、类别、简短说明和查看详情。拖动地图不会丢失当前选择，点击海洋可关闭详情。地图定位按钮依据当前遮挡区域调整镜头。

图层以“国家、自然、地标”分组；允许自然地理叠加国家。首发不显示没有实现的 3D 开关。无深度内容显示“基础资料”，无下载显示“下载后离线阅读”。地图加载失败保留搜索和国家列表替代入口。

### M03 国家百科

S03 为国家卡片目录，支持洲筛选与名称排序，卡片显示国名、代表实景与内容状态。S04 顶部是实景与国名，其下为位置/首都等简明资料、三个特点、十栏目入口、代表地标、历史线与来源入口。长页面使用吸顶栏目导航，首屏不挤入所有内容。

每个栏目进入 S05，展示一段引言及有关文章/地点。保存与下载独立操作；收藏不等于已下载。历史事件提供具体年代与上下文，读过标记不遮挡栏目标题。

### M04 地标与风景

地标页先呈现名称、实景、位置与一句介绍，其后回答“它在哪里 / 如何形成或建造 / 可以观察什么”。图片点击进入全屏查看器，返回仍在原滚动位置。

查看器支持缩放与滑动，图注和来源可以收起；至少保留清晰的返回动作。图库加载失败展示文字说明并可重试。观察问题只使用当前照片中真实可见的细节，避免提示孩子寻找照片中没有的物体。

### M05 跨国专题

目录按明确问题组织，不只放抽象分类名称。专题详情包含引导问题、总览地图、三到五个阅读节点与相关国家。节点可以自由进入，阅读状态表示已看/未看，不加锁。

主题路线是知识组织关系，不宣称旅行交通路径；地图连线仅表达关联，标明探索顺序。未下载节点显示简介和下载入口，已下载节点仍可阅读。

### M06 搜索

S11 输入框自动聚焦但不主动请求麦克风权限；首发只显示文字输入。最近浏览与建议问题来自本机和编辑内容。S12 按“全部、国家、地点、文章、专题”筛选；每条显示类型、名称、摘要、相关国家、离线状态。

搜索“尼罗河”可返回地理地点、相关文章与专题。零结果文案“还没找到这个内容”，提供检查名称和浏览国家；搜索错误保留输入。相似地名附所属区域，避免只有名称无法区分。

### M07 阅读与聆听

文章包含标题、国家/栏目、概览、分节正文、图注、词语解释、延伸文章和来源。屏幕底部工具栏提供目录、听讲解、收藏、记笔记。正文优先保持宽松行距与短段落。

朗读中工具栏显示播放/暂停与当前段落；字号、语速使用带即时预览的面板。难词打开解释底部面板，关闭后返回原段。来源查看后返回同一位置。无语音资源时说明“这台设备暂时没有可用的中文语音”，文字阅读可继续。

### M08 互动理解

每次一题，显示第几题与跳过入口；题目文字和选项完整可见，选择后再提交。定位题提供有语义标签的替代选项列表。反馈用解释、图示和回读按钮说明原因；正确/待重试由图标和文字共同表示。

答错不扣分、不阻止阅读。退出时保存本轮题号；从文章进入时返回原文章。完成页面以“你发现了……”总结知识，支持结束，不自动开始下一轮。

### M09 我的探索

首页呈现继续阅读、收藏、读过的国家与笔记入口，不展示虚构连续签到或排行榜。笔记分“我的发现”和“还想知道”，可关联文章/地点。

编辑时显示正在保存/已保存/保存失败；显式完成按钮便于孩子理解。退出有未保存变更时保留草稿或询问是否放弃。空收藏提供去地图/百科的入口；关联内容已移除时保留笔记和标题，提供重新下载。

### M10 家长与离线

家长中心显示阅读偏好、休息提醒、内容包与本机记录入口。防误触步骤不能称为身份认证。休息提醒允许稍后处理，不能称为强制限制。

内容包列表呈现包名、文章/地标范围、大小与状态：未下载、下载中、已安装、可更新、失败。每种状态只有对应的有效操作。下载中显示已下载字节与取消；失败说明原因和重试；移除说明个人笔记会保留。

备份导入先展示文件识别和条目摘要，再选合并/覆盖；不在选择文件后直接覆盖记录。危险动作使用明确名称和确认，成功后有可理解反馈。首次 Web 访问与完整原生离线能力分别说明。

## 4. 全局状态与文案

| 场景 | 反馈 | 后续动作 |
| --- | --- | --- |
| 正在读取本机内容 | 与页面结构一致的短暂占位 | 自动显示内容 |
| 内容包未下载 | 简介 + 内容范围 + 实际大小 | 下载或返回 |
| 网络不可用 | “暂时连不上网络，已下载内容还能看” | 查看已下载 / 重试 |
| 图片失败 | 保留图注、灰底占位 | 单图重试 |
| 保存失败 | “这条记录还没有保存成功” | 重试 / 保留草稿 |
| 搜索为空 | 说明没有结果 | 修改词语 / 浏览国家 |
| 内容被新版替换 | 保留标题和个人记录 | 打开对应新内容或返回目录 |
| 缺少中文语音 | 简短说明设备语音不可用 | 继续阅读 / 家长设置 |

## 5. 设计稿交付边界

本轮交付 10 张模块设计图，每张包含该模块的核心页面或关键状态，覆盖上表的主画面。它们不是全部 28 个页面与所有状态的逐像素实现稿。剩余页面遵循本文与共用组件，在实际 Flutter 实施前补齐对应布局；P1/P2 不因出现在文档中就视为已完成设计或开发。

生成图中的文字如有局部偏差，以本规格的文案、字段和导航为准。每张图的提示词、实际文件与检查记录在设计交付索引中保存。
