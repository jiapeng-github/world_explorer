机器清单中的段落 ID 为预分配，evidenceBlockIds 标记 planned；全文完成后须缩小到直接支持答案的准确段落，不可整篇笼统作证。题目未选时禁用提交；解释可回到证据，返回保存选择。内嵌与独立页面共用同一 attempt。

开放观察不打分，不预填回答。图片只提供观察条件，至少一个字段非空即可保存；空白、草稿、保存成功、保存失败、返回恢复均需实现。
