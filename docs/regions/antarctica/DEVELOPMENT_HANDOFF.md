# 南极洲 · Flutter 开发交接

2026-11-14。本文是后续实施约定，本轮不修改 lib、assets/atlas/catalog.json 或数据库。用户已决定暂缓内容更新服务，本专题先内置，不引入服务器依赖。

## 数据身份与兼容

现有 AtlasArticle、AtlasPlace 的 `countryId` 为必填，AtlasCountry 又含首都、国旗等字段。南极洲不能简单塞成一个深度国家。建议新增统一 `ContentScope(kind, id)`，kind 首批支持 country、region；新增 `AtlasRegion` 与目录 `regions[]`。

```json
{
  "id": "antarctica-ice-shelf",
  "scope": {"kind": "region", "id": "antarctica"},
  "sectionId": "ice",
  "revision": 1
}
```

- 旧文章缺少 scope 时，从既有 countryId 解析为 country scope；旧国家 JSON、稳定 ID、收藏和笔记不改义。
- 新 region 内容不填伪造 countryId，不通过“空国家对象”骗过阅读器。内容仓库统一按 scope 查所属资料、文章、地点、题目与路线；向旧页面提供兼容 getter，但新逻辑不依赖它。
- 增加 region 收藏类型和专题记录入口；文章、地点继续使用现有稳定实体 ID。统计聚合按 scope，12 国不因新增南极洲变成 13 国。
- 个人记录／备份如有类型枚举或外键，应增加兼容迁移与 schemaVersion；旧备份仍可导入。新备份的 region 字段不能被旧解析静默丢失；不支持时明确版本提示。
- 当前世界基础表中的 `ata` 保留作地图来源实体，通过显式 registry 映射，不复制成第二个可见国家条目。

## 复用与新增

|复用|新增或调整|
|---|---|
|全局主题、响应式导航、照片来源查看|地区专题首页、目录、时间线与 region 入口|
|文章目录、段落定位、术语、TTS、收藏笔记|阅读器所属内容跳转从 countryId 改为 scope|
|闭合题、证据回读、答题恢复|极地定位题、食物网方向与冰类分类题|
|SQLite 记录、草稿、备份恢复|region 统计、收藏、备份兼容|
|通用地图控件、照片抽屉、地点详情|EPSG:3031 投影适配器、极点和日期线处理、冰架图层|
|现有国家内阅读路线模式|南极 3 条路线，复用阅读状态而非独立“通关”状态|

建议目录：`lib/features/regions/antarctica/`；地图适配器放 `lib/map_engine/`；资料包 `assets/atlas/regions/antarctica/`。不复制一份完整阅读器造成两套行为。

## 版本与安装

本期随 App 内置所有南极正文、地图与图片；无网时可搜索、阅读和记录。安装资源大小在真实素材冻结后计算，不在设计阶段虚报 MB。已经存在的国家包管理保持原状态，本轮不接远端索引、更新发现、断点续传或发布服务器。
