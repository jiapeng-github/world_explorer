## 真实素材与设计稿的区别

概念图中的摄影被替换为 20 张署名与许可明确的真实照片，详见 [媒体记录](media-manifest.json)。因此相机角度、动物姿态和建筑外观不与生成图逐像素相同。保留浅底、深海蓝、橙色、实景主视觉、卡片层级和页面结构。中山站使用注明历史性质的站区摄影和真实地理位置卡，不把其他科考站的工作照片标作中山站。

八图解采用可点选的 Flutter 矢量组件，食物网展示五节点和三条取食分支。极昼图按地点与月份切换说明。图形是教学示意，不能拿来测量真实大小。

O01、O04 的最终素材为气象设备与雪面，因此观察提示对应可见的设备与环境，而不是声称提供未取得的吹雪实拍或历史天气数据。没有伪造温度、风速或实际观测表。闭合资料题 P05 考查比较记录的条件，不把无日期风景照片当作冰量变化证据。

## GIS 与来源

`assets/atlas/antarctica-coast.json` 包含 2,215 个 SCAR ADD v7.13 几何要素，EPSG:3031 米坐标。下载冻结于 2026-11-14，查询时按 1,000 米概化，保留 land / ice shelf / ice tongue / rumple 分类。绘制时仅翻转屏幕 Y 轴；地点使用同一极地投影。

数据：Gerrish 等，2026，Medium resolution vector polygons of the Antarctic coastline，v7.13。CC BY 4.0。[DOI](https://doi.org/10.5285/96ffb7ba-69a9-4ec3-aede-07e746f1555a)。官方服务元数据、许可、查询和文件校验值保存在 [GIS 来源记录](gis-source.json)。不同区域资料精度不同，本图用于概览，地点标记为代表位置，不提供实时海冰或导航。

文章来源依各自 S01–S18 引用接入。五段内容保持稳定段落 ID，闭合任务链接具体段落。正式出版前仍可另行做独立地理编辑审读；自动测试并不等于独立专家审核。
