# 南极洲 · 极地地图规格

2026-11-14 · 设计要求，尚未取得或处理正式 GIS 资产。

## 范围与投影

主图南极点居中，建议使用 **WGS84 / Antarctic Polar Stereographic（EPSG:3031）**：南极为投影中心，中央经线 0°，标准纬线 71°S。所有源数据先识别 CRS，再统一转换；不能把投影米坐标当成经纬度。

默认固定地图朝向：0° 经线向上，90°E 在右，180° 向下，90°W 在左。南极点的经度没有唯一地理意义，计算上使用 0° 作为规范值；接近或位于 -90° 时使用明确极点分支，避免无穷大、NaN 或跳到北半球。

“全洲／南极半岛／罗斯海”为同一底层坐标系的相机预设，不是把三个地区拼成错位地理。各视图独立保存中心和缩放；比例尺随视图变化。跨日期变更线的罗斯海和冰架必须保持连续，不能因 ±180° 切开而出现跨屏长边。

南极圈用按历元计算的纬线绘制，教育文字“约南纬 66.56°”；同心圆只能来自投影后的纬线，不从概念图描线。南极半岛部分伸到南极圈以北。条约适用的 60°S 与南极圈不同；需要时在说明中区分，不作装饰性的多圈叠加。

## 资产与图层

|图层|首选资料与要求|无资料时的处理|
|---|---|---|
|海岸、陆地、冰架|SCAR ADD 分类几何；记录版本、许可、发布日期与源摘要；严格区分陆地／冰架／冰舌|Natural Earth 仅供低精度世界入口，不能当精细冰架边界|
|地形背景|来源明确的南极 DEM、阴影或卫星拼图；记录投影与年代|使用干净的矢量底图，保留山地代表点，不把模糊图放大冒充细节|
|山脉、岛屿、海域|SCAR 地名与可靠地形记录；范围精度适配缩放|只有代表位置时明确“代表位置”，不捏造完整多边形|
|地点、科考站|SCAR／COMNAP／各科考机构坐标与名称；站点运营与研究内容另核|经过核验的地点列表作为稳定入口|
|季节海冰（选做）|NSIDC 等有时间、浓度阈值和许可的快照；一次冻结同一产品的对照期|关闭真实分布层，只在文章提供清楚标注的原理图|

基础层不展示领土主张扇区、旅游线路、实时天气或未经核验的站点开放状态。动物代表图标不等于完整分布图，企鹅不在地理南极点内陆出现。

## 几何与交互

- 世界图现有 `ata/AQ` 实体映射到 `region:antarctica`。`atf/TF` 是另一既有地理条目，不自动并入同一内容或领土解释。
- 点、线、面分别命中；山脉／海域有面才支持面命中，否则提供代表点。不同类别同时用形状、线型、标签区分。
- 地点靠近时聚合，展开可读列表；相机聚焦为选中对象留出抽屉空间。点击选择不直接完成定位题。
- 主地图在极点不画“朝屏幕上方就是北”的箭头；以经线标记解释方向。局部视图如显示北向，须从当前位置投影方向计算。
- 比例尺用当前锚点附近的椭球测地距离计算，或明确局部近似误差；不从图稿固定写死 1000 km。说明极地投影仍有比例变化，不能按像素直接比较全球面积。
- 半岛、罗斯海、南极点、各离岛、-180°/+180°、靠海的冰架边缘、缩放最小最大级都需有回归用例。
- 提供搜索列表、复位、来源／图例；桌面键盘可选择，读屏可得到选中名称与位置描述。

## 审核与验收

先核 12 地点是否位于正确区域，再核源几何、图层顺序、覆盖范围、坐标变换正反向与线段接缝。正式图上不能直接复用生图的大陆轮廓、等高线、冰架形状、经纬标注或比例尺。

地图资料入口已检索到 SCAR ADD，数据目录直开返回 403；本轮仅确定资料方向，**没有声称已获得数据或授权**。实际许可、版本、海岸年代和可重分发条件须在开发时逐项确认；必要时用许可明确的替代来源，并在实现记录注明精度差异。
