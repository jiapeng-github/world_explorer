## 编辑核验重点

1. 海冰、冰山、冰架、冰盖及接地线分别解释；冰架的范围随时间变化，采用版本化资料。
2. 帝企鹅、阿德利企鹅、帽带企鹅与海豹物种逐一核对；生成图不进入科学证据媒体库。
3. 昼夜按纬度与月份说明；科学图中太阳光方向、地轴与明暗面一致，不把周年变化画成地轴任意转向。
4. 旧网页的概述和数字可能过时或过度简化；优先原始资料与明确范围。设计不使用缺年份的面积排名、人员数量、动物总数、实时冰量。
5. 科考站生活写明具体站点与时期；任何儿童观察题都需指向可见细节或已审核正文。
6. 本轮仅核对设计关键概念；逐段来源、真实媒体许可、全部坐标、题目证据与独立编辑终审在实现阶段完成。
