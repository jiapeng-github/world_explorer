# 中国地图展示修复

修复第三方 `NAME_ZH` 直接进入 UI、台湾几何被独立处理的问题。

- 世界概览、细节和源地图均将 TWN 的原有多边形并入 China/CHN；保留实际海岸几何，不绘制海峡上的连接面。
- 移除独立 twn 国家目录，地图不额外显示台湾名称或圆点；点击返回中国并联动高亮。
- 钓鱼岛采用公开坐标 25°44.6′N、123°28.4′E，以无文字的小尺寸可点击代表点表示，并关联中国、联动变色。点符号不是岛屿边界，不用放大的虚构多边形代替岛屿。
- 中国学习地图与全局搜索补充台湾、钓鱼岛入口；旧 twn 国家链接、仓库查询和旧收藏标题兼容中国入口。
- 构建脚本同步处理国家分组，避免重新生成资源后恢复错误。

坐标来源：[外交部钓鱼岛专题：地理坐标](https://www.fmprc.gov.cn/diaoyudao/chn/zrhj/201510/t20151009_8520998.htm)。地图原始几何仍来自 Natural Earth；上述分组与标签为本产品展示配置，不是对上游原始分类的原样照搬。

验证：`test/china_map_identity_test.dart` 检查两级几何包含台湾、无独立 twn 条目、搜索与旧 ID 兼容、真实屏幕点选台湾／钓鱼岛回调中国。另运行中国地图及内容仓库回归、地图生成器测试和静态分析。
