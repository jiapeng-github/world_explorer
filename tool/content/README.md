# 离线内容制作

`build_catalog.py` 合并旧版已存在的三国内容、Natural Earth 国家目录和 `editorial/*.json` 补充内容，输出 `assets/atlas/catalog.json`。旧版文章 ID 保持稳定，用于迁移阅读记录。补充文件中的文章、地点、媒体和题目按稳定 ID 完整替换或新增；同一个文件重复 ID 会失败。国家栏目按键合并、来源按 URL 去重，中国和埃及的第二版正文与各自的 `*_assets.json` 素材清单分开维护。

```sh
python3 tool/content/build_catalog.py
python3 tool/content/validate_catalog.py
python3 -m unittest discover -s tool/content -p 'test_*.py'
```

2026-11-09 内容现状为 177 个国家与地区基础条目，7 个有正文的国家，121 篇文章、45 处地点、8 个专题、84 道活跃理解题和 116 项媒体。美国首版包含 30 篇正文、12 处地点、24 道闭合题、6 项开放观察和 36 项实拍、卫星影像或档案。埃及与中国第二版各包含 30 篇正文、12 处地点、24 道闭合题和 6 项开放观察。深度首发目标仍为 20 国、160 篇文章、100 处地标和 160 张照片。

补充稿为适合儿童的原创短文，事实经列出的官方来源核对。`sourceChecked` 表示已核对来源，不表示已通过独立人工编辑审核。文章与国家来源均保留 URL 和核查日期；时间线采用 `period/title/body` 字段。动态人口数字没有在新稿中填入无年份的估计值。

图片与事实来源分开管理。中国第二版使用不同主题的照片与作品图，并明确圈养熊猫、普通稻田与实际案例、没有确切地点的龙舟照片等范围。其他国家仍可能复用已许可的国家景观作为封面，不能将其误称为饮食、校园或表演活动实拍。地点只有在照片确实拍摄该对象时才填写 `mediaIds`。地图点是观察位置，不作为精确导航坐标。

中国第二版国家和文章的 `revision` 为 2；重写正文采用新段落 ID，客户端应保留旧收藏、笔记和历史记录，但不把旧版完成状态自动算作新版已读。`china-transport` 旧题在 `archivedExercises` 中保留，其文章关系纠正到 `china-canal-history`；活跃目录不展示该归档题。`china_validation.py` 对 30 篇、24 题、6 个开放活动与各篇证据绑定做专门验收。

`egypt_validation.py` 另检查埃及内容的稳定 ID、正文长度、六种图解、热点、媒体字节与区域底图摘要。`usa_validation.py` 检查美国篇目覆盖、阅读长度、地图题候选、观察活动和媒体摘要。

校验器检查 ID 唯一性、跨实体关联、正文与来源、十个栏目、时间线字段、理解题答案与依据、经纬度范围以及媒体许可和实际文件。它不代替内容事实审校、授权复核和地理边界审核。
